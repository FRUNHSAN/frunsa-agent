# V4.1 Phase 2 计划 — 引擎点火

> **当前**: `cloud_llm.generate()` 直接被 repl.py 调用，三引擎架空。
> **目标**: Router 分出 Track A/B。复杂任务走 Planning→Orch→Critic 全链路。

## 现状

```
repl.py → cloud_llm.generate(full_prompt) → 输出
          ↑ 三引擎完全被绕过
          
engines/planning/   — PlanningEngine (任务拆解)
engines/orchestration/ — OrchestrationEngine (工具调度)
engines/critic/     — CriticEngine (反思修正)
```

三个引擎各有完整实现、conformance 测试。架构正确。但 `main.py` 没接。

## Phase 2 三步走

### Step 1: Track Router (15 行)

```python
# core/repl.py 中替换 cloud_llm.generate()
def _route_and_generate(user, system, trust, bp):
    if _is_complex_task(user):
        return _track_b_agentic(user, system, trust, bp)
    else:
        return cloud_llm.generate(f"{system}\n\nUser: {user}")
```

**复杂任务判定**：
- 包含"帮我"、"怎么"、"分析"、"方案"、"比较"、"你觉得" → Track B
- 工具调用标记 (`<tool_call>`) → Track B
- 其他 → Track A (直连)

**X-Ray 日志**：
```

[🔀 Track B] Orchestration → 调度 knowledge_search

```

### Step 2: Track B 管线 (30 行)

```python
def _track_b_agentic(user, system, trust, bp):
    # 1. Planning: 拆解任务
    plan = planning_engine.plan(user, context=system)
    
    # 2. Orchestration: 执行每个子任务
    results = []
    for step in plan.steps:
        if step.needs_tool:
            check = action_pipeline.check(step.tool_name)
            if not check["allowed"]:
                results.append(f"[被契约拦截: {check['reason']}]")
                continue
            results.append(execute_tool(step))
        else:
            results.append(cloud_llm.generate(step.prompt))
    
    # 3. Critic: 反思结果
    critic_output = critic_engine.evaluate(results, plan)
    
    # 4. 合成最终回复
    return synthesize(results, critic_output)
```

### Step 3: 契约贯穿全链路

引擎的每一步都经过契约校验：
- Planning 拆解 → 检查 autonomy 是否允许自主规划
- Orchestration 调度 → ActionPipeline.check() 每个工具
- Critic 反思 → 检查 tone_style + initiative 是否允许批评用户
