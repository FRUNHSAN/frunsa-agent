在 Godot GDScript 中，如何限制一个导出变量只能在 0 到 100 之间取值？
在 Godot 的 GDScript 中，如果你想要限制一个导出变量（`export`）的取值范围只能在 `0` 到 `100` 之间，你可以使用 `@EXPORT_RANGE` 注解来实现。这个注解允许你设置最小值和最大值。

下面是完整的 GDScript 示例代码：

```gdscript
extends Node

# 导出变量，限制在 0 到 100 之间
@EXPORT_RANGE(0, 100)
var my_value: int = 50
```

### 解释：
- `@EXPORT_RANGE(min, max)`：这是 GDScript 的元数据注解，用于在编辑器中限制导出变量的输入范围。
- `my_value: int = 50`：这是一个整数类型的导出变量，默认值为 50。

### 如果你想用浮点数：
如果你想让变量是浮点数，并且限制在 `0.0` 到 `100.0` 之间，可以这样写：

```gdscript

var my_float_value: float = 50.0
```

### 注意事项：
- `@EXPORT_RANGE` 只在 Godot 编辑器中生效，不会在运行时自动限制值。如果你需要在运行时也进行验证，可以在 `set` 方法中添加逻辑。
- 如果你需要更复杂的验证逻辑（例如只允许特定值、或根据其他条件变化），可以使用自定义的 `set` 和 `get` 方法。

**PROPERTY_HINT_FLAGS 和 PROPERTY_HINT_ENUM 的区别：**

1. **PROPERTY_HINT_FLAGS**
- 用于表示一个整数（`int`）属性，该属性的值代表一组**位标志（bit flags）**。
- 每个位代表一个独立的选项或状态，例如：
```cpp
enum {
FLAG_A = 1 << 0,
FLAG_B = 1 << 1,
FLAG_C = 1 << 2,
};
```
- 在编辑器中，会以**复选框形式**显示每个标志，用户可以单独开启或关闭。
- 适用于需要组合多个开关状态的场景，比如权限设置、功能开关等。

2. **PROPERTY_HINT_ENUM**
- 用于表示一个整数（`int`）属性，该属性的值是**预定义的枚举值之一**。
- 每个值对应一个名称，例如：
```cpp
enum {

ENUM_VALUE_B,
ENUM_VALUE_C,
};
```
- 在编辑器中，会以**下拉菜单形式**显示这些选项，用户只能选择其中一个值。
- 适用于需要从有限选项中选择一个值的场景，比如角色类型、状态机状态等。

---

**什么时候使用哪个？**

- 使用 **PROPERTY_HINT_FLAGS**：
- 当你需要表示多个独立的布尔选项（开/关），并且这些选项可以同时被启用。
- 例如：`is_visible`, `is_interactive`, `is_collidable` 等。

- 使用 **PROPERTY_HINT_ENUM**：
- 当你需要从一组固定的选项中选择一个值。
- 例如：`player_type = "warrior"`, `"mage"`, `"archer"` 等。

2. **调整范围**：将这个值从 [0, 1) 映射到 [-10, 10]。



lerp() 和 lerp_angle() 有什么区别？为什么旋转插值要用后者？
**Answer:**

`LERP()` 和 `LERP_angle()` 的主要区别在于它们处理插值的方式，尤其是当涉及到**角度**（如旋转）时。

---

### 1. **`LERP()` 的作用：**
- `LERP(from, to, weight)` 是一个**线性插值函数**，它在两个数值之间按比例进行线性插值。
- 它适用于普通的数值范围（如颜色、位置、缩放等），但**不适用于角度**，因为角度是**周期性的**（0° 和 360° 是同一个方向）。
- 例如，如果使用 `LERP(0, 2*PI, 0.5)`，它会返回 `PI`，这是正确的。但如果从 `PI` 到 `PI + 5*TAU`（即绕了多圈），`LERP()` 会直接线性地从 `PI` 插值到 `PI + 5*TAU`，这会导致**不必要的绕圈**，而不是选择最短路径。

---

### 2. **`LERP_angle()` 的作用：**
- `LERP_angle(from, to, weight)` 是专门用于**角度插值**的函数。
- 它会自动选择**最短路径**来插值两个角度，避免不必要的绕圈。
- 例如：
- `LERP_angle(0, PI, weight)` 会沿着**逆时针方向**（最短路径）插值。
- `LERP_angle(0, PI + 5*TAU, weight)` 会沿着**顺时针方向**（因为此时顺时针更短）插值。
- 这是因为 `LERP_angle()` 会考虑角度的**周期性**和**浮点精度问题**，确保插值结果符合预期。

---

### 3. **为什么旋转插值要用 `LERP_angle()`？**
- 旋转是一个**周期性**（循环）的值，比如 0° 和 360° 是同一个方向。
- 如果用 `LERP()` 来插值两个角度，可能会导致**不自然的旋转**（比如从 350° 到 10°，`LERP()` 会直接从 350° 线性插值到 10°，而不会选择最短路径 10° → 350°）。
- `LERP_angle()` 会自动判断哪条路径更短，并选择那条路径进行插值，从而实现**平滑、自然的旋转效果**。

---

### 总结：

| 特性 | `LERP()` | `LERP_angle()` |
|------|----------|----------------|
| 用途 | 普通数值插值 | 角度/旋转插值 |
| 周期性处理 | 不处理 | 自动处理 |
| 最短路径 | 不保证 | 保证 |
| 适用场景 | 颜色、位置、缩放等 | 旋转、角度变化 |

因此，**在处理旋转或角度变化时，应该使用 `LERP_angle()` 而不是 `LERP()`，以确保插值过程自然且符合物理逻辑。**
