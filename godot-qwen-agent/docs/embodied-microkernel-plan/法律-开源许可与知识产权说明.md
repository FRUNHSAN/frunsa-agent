## 二、为什么不用其他许可证

| 许可证 | 致命问题 |
|--------|---------|
| **MIT** | 无专利保护。别人可以在你的内核上申请专利，反过来起诉你侵犯他们的专利。Apache 2.0 的 §3 专利授权终止条款防止了这一点："如果你起诉我的专利，你用我代码的授权自动终止。" |
| **GPLv3** | "传染性"——企业链接了 GPL 代码就必须全部开源。腾讯法务会直接毙掉。 |
| **AGPLv3** | 比 GPL 更严格——即使只通过网络提供服务（不分发二进制），也要开源。青云计划如果是 SaaS/云服务形态，AGPL = 法务自焚。 |
| **CC BY（仅署名）** | 别人可以拿你的文档改一改，用付费墙锁起来卖。CC BY-SA 的"SA（相同方式共享）"确保衍生文档也必须免费公开。 |
| **CC BY-NC（禁止商用）** | 腾讯和课题组用你的文档做内部培训、组会报告——在 CC 定义下可能算"商业使用"。BY-NC 会导致法务不敢碰你的文档。BY-SA 允许商用，但要求衍生品也 CC BY-SA——足够保护你。 |
