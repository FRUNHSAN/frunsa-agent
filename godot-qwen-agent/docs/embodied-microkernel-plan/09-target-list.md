### 日本套磁特别注意

- **内诺制**：教授的个人意愿决定录取。套磁信必须：
  1. 提及教授的至少一篇具体论文（不是"贵研究室的领域"——是"您 2025 年在 ICRA 发表的 XXX"）
  2. 说明你的内核如何与那篇论文的具体问题对接
  3. 用日文敬语开头（见模板 1）
- **入学时间**：日本大学院通常是 4 月或 10 月入学。提前 6-12 个月开始套磁。

## 五、套磁前调研清单（每个目标做一遍）

- [ ] 找到该组近半年的 3 篇代表作（Google Scholar / 实验室官网）
- [ ] 找到你的内核能与之结合的"锚点"（具体到某篇论文的哪个 section 的哪个 open problem）
- [ ] 确认该组的招聘/招生状态（是否有名额？什么时间入学/入职？）
- [ ] 找到通讯作者/一作的邮箱（论文底部 affiliation + email）
- [ ] 准备一个针对该组的具体技术问题（在套磁信里问——不是在结尾问"有没有名额"）
- [ ] 如果是日本教授：确认教授的专攻和研究室名称（不是学院名称——是研究室名）
