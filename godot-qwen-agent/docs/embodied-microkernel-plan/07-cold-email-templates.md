# 07 — 套磁信模板库

**定位**：实际发送时直接套用。每类模板针对不同的收件人和场景。

> 参见：[02-technical-proposal.md](./02-technical-proposal.md) — 附件（技术提案）  
> 参见：[06-interview-strategy.md](./06-interview-strategy.md) — 面试话术（套磁成功后的下一阶段）

---

## 通用原则（适用所有模板）

1. **第一封邮件只放正文 + 1 个附件**（技术提案 PDF）。不要把所有东西砸过去。
2. **正文控制在 300 字以内**。教授/Leader 每天收 50+ 封套磁信。
3. **必须包含**：读过对方哪篇论文 + 你的核心连接点 + 一个具体问题。
4. **附件内容**：技术提案（3-5 页 PDF）+ GitHub 链接。不要附简历——简历在教授回复后再发。
5. **结尾用"无论是否有幸加入，都期待能交流"**——弱化功利性。

## 模板 4：针对"以人为中心的具身交互"课题组定制版

```
标题：【实习申请 / 学术探讨】关于具身社交交互的决策层架构——一个正在验证的想法 — [你的姓名]

[老师姓名] 老师您好，

我拜读了贵组的课题描述——"面向以人为中心的具身交互智能体研究"，
对其中六个具体工作深有启发。

我特别注意到：
- 工作 4（人机协同决策）涉及连续状态空间中的博弈与任务分配
- 工作 6（跨场景自适应）需要一致的控制策略和安全性保证

您认为离散规则引擎和连续 ODE 状态空间，
哪个更适合处理"社交礼仪约束"的模糊性和场景依赖性？
我很想听您的看法。

期待您的回复！
```
