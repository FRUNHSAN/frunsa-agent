# 01 — 三代工程范式

**Last-verified-against-code**: `7e73374` (2026-07-04)
**预计阅读时间**: 10 分钟
**文笔配比**: 灵感 40 : 严谨 60

---

人类历史上所有"造物"的方式只有三种。不是程度的差异，是存在论层面的断裂。

---

## 第一代：指令式 — 人直接造物

**核心逻辑**：你想要什么结果，你就精确控制每一个步骤。

打铁。烧砖。写汇编。牛顿力学是它的数学，CAD 是它的工具，`MOV AX, 0x01` 是它的极限表达。

**设计者 = 控制者。** 人的意志直接映射到物质世界。每一步都是预设的，每一个变量都是已知的。如果结果不对，那是人算错了——重新算一遍就好。

这在简单系统中是完美的。当系统的自由度少于人的计算能力时，指令式是最优解。

它在复杂系统中是灾难。当系统的自由度超过人的计算能力时，指令式必然失稳——你无法穷举所有情况，你写的每一条指令都有一个你没考虑到的边界条件。而真实宇宙的自由度是无限的。

**指令式不是"错了"。它只是带宽不够。**

---

## 第二代：自动化指令 — 人造机器，机器造物

**核心逻辑**：人写指令给机器，机器再把指令翻译成更细粒度的指令给物质。

数控机床。编译器。流水线。Fortran → 汇编 → 机器码 → 电信号。人不再直接控制每一步，但人仍然控制**指令的生成规则**。

**设计者 = 元控制者。** 人不再规定"每一步怎么走"，而规定"生成步骤的规则"。编译器不执行你的程序——它把你写的程序翻译成机器能执行的指令。你控制的不是结果，而是结果的语言。

这在工业时代是革命性的。但它没有改变根本范式——控制链仍然是从人的意志出发的。自动化指令只是把指令的翻译过程自动化了，没有把指令的生成过程解放出来。**你还是得告诉系统"做什么"——只是你可以用更抽象的语言说了。**

---

## 第三代：约束式 — 人定义约束，系统自主涌现

**核心逻辑**：人不规定"做什么"，人只规定"什么不可以做"。系统在约束定义的可行域内，按照自身的动力学自行收敛到解。

AlphaFold 不画蛋白质的图纸。它定义能量函数的边界——疏水基必须朝内、氢键必须配对、主链不能交叉——然后让分子自己找到最低能态。蛋白质折叠成唯一正确的三维结构。没有人告诉它怎么折叠。没有步骤。只有约束 + 梯度下降 = 涌现。

**设计者 = 约束定义者。** 人的意志不再直接映射到物质世界。人在状态空间中画出一条边界——"此线以内，物理定律允许；此线以外，物理定律禁止"——然后放手。系统自己在边界内找到解。

这和"放任自流"是两回事。真菌的基因组也定义了极其严格的约束——细胞膜不能破裂、渗透压必须在范围内、蛋白质折叠不能超过能量上限。这些约束非但不减少自由度，反而**创造了涌现的可能性**——约束把无限的搜索空间压缩到了有意义的子空间。没有约束的"自由"是噪声。有约束的自由才是涌现。

---

## 不是程度差异，是方向断裂

三代范式之间不是 "2.0→3.0 的渐进升级"。指令和自动化指令在同一条轴上——都在控制系统的路径。约束和它们垂直——它在控制系统的**地形**。

| | 指令式 | 自动化指令 | 约束式 |
|---|--------|----------|--------|
| 人控制什么 | 每一步 | 指令生成规则 | 可能性空间的边界 |
| 系统做什么 | 执行 | 翻译 + 执行 | 涌现 |
| 自由度 | 0（完全预设） | 低（翻译环节有弹性） | 高（边界内自由） |
| 面对未知 | 失效——没写指令 | 有限适应——规则可泛化 | 自主适应——涌现新解 |

---

## 约束不是启发式

> **这是整份文档体系最核心的理论锚点。如果不讲透，约束式工程在懂行的人眼里就变成了"换了一个词的 heuristic"。**

这两个概念在表面上很容易混淆——它们都"不追求绝对精确"，都"允许系统自行探索"。但它们在存在论层面是**相反**的。

### 一句话定义

- **启发式（Heuristic）**：人类经验硬编码成的"搜索捷径"——控制的是**路径方向**。"优先往那边走，因为以前这么走成功过。"
- **约束式（Constraint）**：物理/数学法则雕刻出的"可能性空间"——控制的是**地形形状**。"哪里不能去，哪里是悬崖，因为物理定律不允许。"

### 核心差异矩阵

| 维度 | 启发式工程 | 约束式工程 |
|------|----------|----------|
| 控制对象 | 搜索方向（路径捷径） | 状态空间形状（能量景观） |
| 知识来源 | 人类过去的经验（"上次这么走找到了"） | 系统的底层物理/数学法则（"热力学不允许往那走"） |
| 与指令范式的关系 | 指令范式的**降级版**——写不出完美指令就写经验法则 | 指令范式的**彻底反叛**——根本不写路径指令 |
| 面对 OOD | 脆弱——经验不管用就失效 | 鲁棒——只要底层法则没变，系统自行涌现新解 |
| 时间箭头 | 向后看——从历史数据总结规律 | 向前看——定义未来可能性的边界 |
| 生物学对应 | 动物的固定动作模式（蜘蛛织网的硬编码步骤） | 细胞的代谢网络（无固定步骤，只有能量约束下的实时涌现） |
| 数学对应 | A* 算法的启发函数 h(n) | 约束优化中的可行域 Ω |
| 隐喻 | 给瞎子一根拐杖（告诉他往哪探路） | 给房间建好墙壁和重力（让他自己摸爬滚打找到出口） |

### 启发式本质上还是"指令范式"

这是最关键的洞察。很多人以为启发式是"第三条路"，其实不是。

启发式是指令范式在算力不足时的**退化形态**。当你无法写出穷举所有情况的精确指令时，退而求其次写"如果 X 则大概率 Y"的模糊指令。但本质上，你仍在试图**控制系统的搜索路径**。你在告诉系统"往哪边走更有可能找到答案"。

A* 算法的 h(n) 是经典例子：它告诉搜索算法"优先展开距离目标更近的节点"。这是人类基于对地形的理解硬编码进去的经验捷径。如果地形和人类预期的不一样（比如中间有一堵没预料到的墙），启发式会把算法引向死胡同。

约束式**不告诉系统"优先往哪走"**。它只做一件事：把不可行的区域从状态空间中切除。在剩下的可行域里，系统按照自身的动力学（梯度下降、热力学、进化……）自行收敛到吸引子。

### 终极检验标准

> **规则在遇到"没见过的情况"时需要人类来打补丁 → 你写的是启发式**
> **规则在遇到"没见过的情况"时系统自行涌现出新解 → 你写的是约束**

### 在 AI Agent 领域的具体体现

现在 AI Agent 领域最火的概念恰好对应这两种范式：

**Prompt Engineering / Heuristic Rules = 启发式。** "如果用户问到代码，优先用 code_interpreter"、"任务失败时先反思再重试"——这些都是人类基于经验写的搜索捷径。有用，但脆弱。

**Harness Engineering / Guardrails = 约束式的初级形态。** "文件操作只能在 sandbox 目录内"、"输出必须通过 JSON Schema 验证"——这些不告诉 Agent "怎么做"，只定义"什么不能做"。

**MPC 微内核 = 约束式的完整形式化。** 不只是 guardrails（被动的红线），而是主动定义状态空间的能量景观。Lipschitz 约束不是"不要走太快"的启发式——它是"物理上不可能走太快"的约束。Schmitt 触发器不是"优先选 A 不选 B"的启发式——它是"A 和 B 之间存在不可逾越的势垒"的约束。

## 四学科同时切换

这不是 Agent 工程的特例。所有前沿工程学科都正在从"指令范式"切换到"约束范式"：

| 学科 | 指令式（过去） | 约束式（现在） |
|------|-------------|-------------|
| **医药** | 化学合成 + 动物试验 | AlphaFold + 虚拟筛选——给物理约束，让分子自己"对锁孔" |
| **量子** | 手动纠错码设计 | 表面码 + 容错阈值——定义错误率上限，让逻辑比特涌现 |
| **材料** | 试错 + 经验配方 | 生成式材料设计——给目标性质约束，让晶体结构自己"长出来" |
| **AI Agent** | Prompt 工程 + 工具链 | MPC 微内核——给 7 条铁律，让行为在约束内涌现 |

**不是巧合。** 计算能力达到了一个临界点，让我们可以只定义边界条件就让系统自行收敛，而不是定义每一步路径。

但有一个学科在这个过程中扮演了特殊角色：**生物学。**

不是因为生物学最先进。是因为生物学是**唯一一个从一开始就只能用约束式工程**的领域。你没办法"指令"一个细胞长成肝脏——你只能给它正确的信号环境（约束）。生物学家一直在做约束式工程——培养基、诱导条件、选择压力——只是不叫这个名字。

当其他学科追到这个临界点时，它们不约而同地发现：**自己需要的新语言，生物学已经用了 38 亿年。**
