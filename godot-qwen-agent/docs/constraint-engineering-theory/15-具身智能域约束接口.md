## 域特点

| 属性 | 值 |
|------|-----|
| 时间尺度 | ms 级（500-1000Hz 控制回路） |
| 约束类型 | 混合约束——安全硬约束（不可妥协）+ 任务软约束（可优化） |
| 物理接口 | ROS2 + ros2_control——内核作为 Custom Controller 插件，共享内存 |
| 安全层 | Safety Arbiter 三层降级——Level 1 平滑 → Level 2 PD 控制 → Level 3 紧急停止 |
| 死亡定义 | 碰撞 / 紧急停止触发（任务死亡）/ 执行器饱和 |
| 当前验证 | 待实现 |

## 铁律在该域的映射

| 铁律 | 在该域的物理含义 |
|------|----------------|
| #1 纯函数边界 | 控制器无副作用——相同传感器输入 → 相同控制输出。实时确定性 |
| #2 连续控制律 | 关节力矩/速度连续——无瞬时跳变。铁律 #2 的物理安全保证 |
| #3 零 NL I/O | N/A——此域无自然语言，但多模态信号（RGB+LiDAR+力觉）→ Observer 统一翻译 |
| #4 形式化可重放 | 控制回放——相同传感器序列 → 相同轨迹。Fail-safe 审计 |
| #5 零动态分配 | 控制线程预分配，无运行时内存分配。实时系统要求 |
| #6 Lipschitz | 关节力矩/速度变化速率有界——对应执行器物理特性和人体安全限制 |
| #7 信息损失可审计 | 多模态→16维的维度压缩损失可量化 |
