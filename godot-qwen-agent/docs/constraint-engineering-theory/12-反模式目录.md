约束式工程中最常见也最危险的 10 种退化形式。每种附带识别方法、危害等级、修复路径、生物学对应。

**AI 协作者在每次代码审查中必须按 Protocol 2 逐项扫描本目录。**

---

## #1 启发式伪装

**症状**：一条规则的合法性来源是"效果好"而非公理推导。

**识别方法**：追问三次"为什么是这个值/形式？"
- "因为效果好" → 警惕
- "因为之前试过别的，这个最好" → 高度可疑
- "因为符合 XX 公理的推导" → 安全
- 三次都追溯到"经验" → **确认为启发式伪装**

**危险**：表面像约束，但无数学基座。面对分布外数据必然失效。**最常见的退化形式**——约束工程师也是人，直觉就是"试出来好用就留着"。

**修复**：追溯公理来源（如果存在），或显式标注 `[来源: 经验推测] [置信度: LOW]`，降级为启发式。

**生物学对应**：迷信。先祖发现"每年这个季节撒种子庄稼就长"——有效，但不理解日照和温度周期。气候偏移时失效。

## #2 过度约束

**症状**：约束数量超过推理能力上限。每个新问题加新约束。

**识别方法**：约束数量 > 铁律数量 × 2 → ORANGE。> 铁律数量 × 3 → RED。

**危险**：超过 7±2 阈值后，组合动力学超出人的推理能力。你不知道新约束和旧约束是否矛盾。

**修复**：触发 Protocol 7 约束健康度审查。优先寻找语义重叠度 ≥80% 的约束对，提议合并。

**生物学对应**：肥胖。每个多余热量都被储存，不被消耗。系统越来越慢。

---

## #3 约束漂移

**症状**：同一约束的参数在不同域中取值差异巨大——悄悄调整参数以适应新场景，但形式不变。

**识别方法**：同一约束在多个域的参数值差异超过 5×。例如 τ 在 Agent 域 = 120s，在物理域 = 0.5s。

**危险**：参数漂移切断形式和参数之间的公理联系——形式还声称自己是"通用约束"，但参数已经完全域特化。

**修复**：回溯该约束的形式推导链。检查是否在其中某个域中"参数替代了形式"。

**生物学对应**：基因漂变。小种群中，随机因素取代选择压力成为基因频率的主要驱动力。

---

## #4 单域幻觉

**症状**：在一个域里验证过的约束被默认为"通用"。

**识别方法**：域通用度 G(C) = 1.0，但从未在其他域验证过。

**危险**：约束实际只在单域有效。换域后**静默失效**——系统不报错，但行为完全不可控。没有崩溃就没有信号。这是约束式工程最危险的失效模式。

**修复**：在新域中立即压力测试。如果约束需要修改 → G(C) 降至 0.5，标注"部分域验证"。

**生物学对应**：岛屿物种。没有天敌的鸟类忘记飞行。入侵物种一来就灭绝。

---

## #5 免疫缺陷

**症状**：只有化学缓冲（ODE 弛豫），没有呼吸调节（TTL/优先级），没有肾脏调节（RL 自适应）。

**识别方法**：系统对中等扰动的恢复时间 > 10× 正常值 → 缺呼吸调节。跨会话学习能力 = 0 → 缺肾脏调节。白细胞无 TTL 上限 → 免疫风暴风险。

**危险**：中等以上危机 → 永久性损伤（信任地板无法恢复）。大规模危机 → 系统崩溃。

**修复**：确保三层缓冲全部到位——ODE 弛豫（防御基底）、Event Bus TTL + 优先级（传播速率控制）、RL 自适应 τ（缓冲容量长期调整）。

**生物学对应**：获得性免疫缺陷（AIDS）。不是缺少某种武器——是整个防御架构崩塌。

---

## #6 自身免疫病

**症状**：免疫系统（白细胞/胸腺筛选）在正常场景下误触发。

**识别方法**：白细胞在非危机场景下触发 QUARANTINE 或显著拉低 peer_trust 均值。误报率 > 5% → FLAG。

**危险**：免疫反应比危机本身更致命。白细胞大量产生 → 消耗系统资源 → 拉低组织液池平均 trust → 触发更多白细胞 → 免疫风暴。和 COVID-19 的细胞因子风暴完全同构。

**修复**：检查胸腺筛选的历史数据覆盖度、降低白细胞敏感度（调高 η）、确保 N_max 硬约束生效。

**生物学对应**：花粉症、类风湿关节炎、1 型糖尿病。免疫系统攻击自身组织。

## #7 约束膨胀

**症状**：约束数量只增不减。每次危机加新约束。从不废弃旧约束。

**识别方法**：约束数量单调递增 ≥ 5 次迭代，无废弃记录。

**危险**：约束体系从"简约铁律"退化为"庞大法规"。法的精神消失在法条中。新加入的协作者无法区分哪些约束还在生效。

**修复**：立即触发 Protocol 7。目标：至少发现一条可废弃或可合并的约束。如果审查后数量仍不变 → Protocol 7 自身可能失效。

**生物学对应**：癌。细胞不凋亡。组织无限增生。最终压迫正常器官致死。

---

## #8 公理腐败

**症状**：为了适配新场景，修改了铁律的数学形式——不是参数调整，是**形式修改**。

**识别方法**：铁律的数学定义在 git diff 中出现实质性修改。

**危险**：最高等级的退化。铁律的形式是整个约束体系合法性的根基。修改形式 = 同时宣称"之前有结构性错误"和"新形式同样正确"——但新形式无 38 亿年级别验证。

**修复**：撤销修改。如果铁律形式确实不适用新场景 → 该场景可能超出约束范式的适用边界（见 09-边界与反驳）。

**生物学对应**：CRISPR 脱靶。修改 DNA 时不慎改了关键基因。细胞可能直接癌变。

---

## #9 数据权威篡位

**症状**：数据从"参数校准器"升级为"形式决策者"。

**识别方法**：用 AB 测试结果、基准分数、统计显著性来论证约束的形式应该被替换。出现类似"p < 0.05，所以 Lipschitz 上限应从 0.30 改为 0.45"的论述。

**危险**：启发式工程的方法论入侵。数据告诉你"什么值在当前数据上表现好"——不告诉你"什么形式在未知数据上不会崩溃"。**形式来自推导，参数来自标定。混淆两者 = 整个约束体系的合法性危机。**

**修复**：检查论点的引用链。如果最终追溯到"数据说……"而非"公理要求……"→ 禁止修改形式。

**生物学对应**：盲目适应。北极熊的皮毛因雪中隐蔽而呈白色。但若气候变暖无雪，不能因"数据表明白色不好"而更改——皮毛颜色来自演化，不来自数据。

## #10 遗忘退行

**症状**：六个月后，不记得某个约束为什么是那个形式。

**识别方法**：`CLAUDE.md` 中该约束的推导链缺失或断裂。追溯链止于"经验值"。

**危险**：遗忘的约束 = 不可维护的约束。在新域中失效时，无法判断是形式错了还是参数标错了——因为已经不记得形式怎么来的。

**修复**：立即补充推导链。最上游必须为某条铁律或已证明的数学不变量。如果追溯不到 → 降级为启发式。

**生物学对应**：阿尔茨海默病。突触还在，但突触为何如此连接——不可考。
