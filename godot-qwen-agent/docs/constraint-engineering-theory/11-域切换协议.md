# 11 — 域切换协议

**Last-verified-against-code**: `7e73374` (2026-07-04)
**预计阅读时间**: 10 分钟
**文笔配比**: 灵感 10 : 严谨 90 — 标准操作流程

---

把一个约束从一个域迁移到另一个域时的标准操作流程。目标是计算并追踪每个约束的**域通用度** G(C)——当 G(C) 趋近 1.0 时，该约束接近物理定律级别。

---

## 协议 1：识别约束的域依赖性

**分离约束的域无关部分和域特化部分。**

| 属性 | 域无关（形式） | 域特化（参数） |
|------|-------------|-------------|
| 是否随域变化 | 否——任何域中形式相同 | 是——不同域取不同值 |
| 来源 | 公理推导 | 域内数据标定 |
| 修改权限 | Protocol 4——铁律不可侵犯 | 可调，但需记录标定方法 |
| 示例 | `‖Δsv‖₂ ≤ ε` | ε = 0.30 (Agent), ε = 0.50 (物理) |

**输出**：该约束的"形式/参数"分离表。

---

## 协议 2：在新域中验证形式的物理存在性

**不是验证"能不能用"——是验证"物理上存不存在对应的现象"。**

| 域 | 形式验证问题 |
|----|------------|
| 游戏引擎 | "物理模拟中是否存在状态跳变的问题？"（有——离散碰撞的数值震荡。→ Lipschitz 形式适用） |
| Agent 对话 | "信任评估中是否存在短时间剧烈变化的问题？"（有——几句对话后信任暴跌。→ Lipschitz 形式适用） |
| 具身智能 | "控制回路中是否存在加速度/力突变的问题？"（有——电机饱和、外力冲击。→ Lipschitz 形式适用） |

如果三个域的回答都是"有"→ 该约束的形式是**域无关的**。

如果某个域的回答是"没有"→ 该约束的形式在该域中无物理对应。标注 `[域: NOT_APPLICABLE]`。**不要强行适用**——那是过度约束（12-反模式 #2）。

---

## 协议 3：标定域特化参数

**同一个约束在不同域取不同参数。标定方法：从保守侧开始 → 逐渐松弛 → 记录失效点。**

标定流程：
```
1. 在该域的模拟环境中设置保守参数（安全侧——宁可过于严格）
2. 运行标准压力测试，记录性能指标
3. 逐步松弛参数，每次松弛后重新测试
4. 记录首次失效点的参数值 → 标注为 [FAILURE_BOUNDARY]
5. 最终参数 = FAILURE_BOUNDARY × 0.7（安全余量系数）
6. 记录标定数据：测试场景、失效模式、安全余量系数
```

**输出**：该域的参数值 + 标定数据 + 安全余量。

---

## 协议 4：记录域的"死亡"模式

**在该域中，约束失效意味着什么？**

| 域 | 约束失效模式 | "死亡"定义 | 死亡后果 |
|----|------------|----------|---------|
| 游戏引擎 | 数值求解发散、穿透 | 一帧穿透 = 死亡 | 该帧的模拟状态不可信 |
| Agent 对话 | trust 跌破 floor | trust < 0.05 = 死亡 | 进入 TRUST_CRISIS，不可恢复 |
| 具身智能 | 碰撞、力矩超限 | 物理碰撞 = 死亡 | 机器/人受损 |

**死亡模式的"严重性"决定了约束的优先级和冗余保护级别。** 硬死亡（碰撞）→ 硬约束 + Safety Arbiter 三层降级。软死亡（信任 crisis）→ 软约束 + 体液池缓冲。

## 域约束通用度计算

```
G(C) = 1 / (需要修改的域数量 + 1)
```

| G(C) | 含义 | 验证要求 |
|------|------|---------|
| 1.00 | 物理定律级别——三个域中都不需要修改 | 需三个域全部验证 |
| 0.50 | 部分通用——在 N 个域中验证，在 M 个域中需调整 | 标注哪些域已验证、哪些需修改 |
| 0.33 | 单域有效——只在一个域中验证 | 禁止称为"通用约束"。标注 `[域特化]` |
| <0.33 | 未充分验证——仅在单个场景中使用 | 标注 `[场景特化]` |

每个约束维护这张表：

```
|------|----------|-----------|----------|
| 形式适用 | YES / NO / UNTESTED | YES | UNTESTED |
| 参数值 | ε = 0.50 | ε = 0.30 | ε = ? |
| 验证状态 | 待楼梯demo | PLAN2盲测 (n=1) | 待ROS2集成 |

```
