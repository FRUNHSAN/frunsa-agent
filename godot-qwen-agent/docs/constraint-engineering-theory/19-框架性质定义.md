不是哲学宣言（那是 00）。不是方法论推导（那是 18）。只写**这个框架是什么**——每个性质一句定义 + 工程实现方式 + 行业对比 + 失效模式。

## 一、目的上的性质

### 约束环境生成器

**定义**：框架不决策。框架只**维持梯度**——膜两侧的势差、体液池中的浓度场、通量预算的分配、膜的边界条件。内核在这些梯度中自行弛豫到吸引子。

**工程实现**：框架代码中不含 `if user_intent == X then do Y`。只含物理约束——扩散方程的 TTL 参数、Schmitt 触发器的上下阈值、Event Bus 的优先级驱逐规则、PoolBridge 的延迟和范围配置。

**不是**：调度器。编排器。决策辅助系统。

| 失效模式 | 行业症状 | 本框架防护 |
|---------|---------|----------|
| 框架开始做决策 → 内核退化 | LangChain Agent 中 LLM 选 tool，框架只包装 API | 铁律 #3（零 NL I/O）+ 公理 2（环境先于智能）——任何决策逻辑进框架 = 违反公理 |

---

### 倒逼内核迭代

**定义**：框架不修改内核。框架**暴露内核的能力盲区**——在新域部署中，约束失效的位置精确指向内核需要扩展的维度/门/槽位。不是"框架告诉内核该改什么"——是"框架提供的选择压力让内核的不足自己浮出来"。

**工程实现**：域通用度 G(C) = 1/(需修改域数+1)。G(C) < 1.0 = 约束不是物理定律。跨域失效的模式被 Protocol 7 健康度审查捕获 → 触发新推理链 → 内核迭代的输入。不是人工判断"该改了"——是跨域数据的统计必然性。

| 失效模式 | 行业症状 | 本框架防护 |
|---------|---------|----------|
| 无选择压力 → 内核在舒适区无限打磨 | 单域 Agent 反复优化 prompt 和个人助手体验，十年发现不了约束不通用 | 多域部署（Agent 对话 × 游戏引擎 × 具身智能）强制暴露盲区 |

## 二、工程上的性质

### 解耦性

**定义**：膜边界。不是"低耦合"设计模式——是**物理隔离**。子框架之间的边界是对特定类型信号不通透的脂双层。没有对应的膜蛋白（接口），信号**物理上不可能**穿过膜。

**工程实现**：子框架不暴露"公开 API"。暴露的是膜蛋白——特定类型、特定方向、特定通量上限的跨膜通道。类型系统强制执行——违反类型 = 编译错误，不是运行时权限检查。

**不是**：微服务。模块化。依赖注入。

| 失效模式 | 行业症状 | 本框架防护 |
|---------|---------|----------|
| 子系统间隐式耦合 → 改一处崩全局 | import 链跨越 5 层架构，循环依赖 | 膜边界 = 物理不通透——无对应膜蛋白的信号无法到达。铁律 #5（零动态分配）防止运行时膜身份漂变 |

---

### 可行性

**定义**：知道先做什么、知道对标什么、知道离目标还有多远。不是"理论上可做"——是**有可执行的下一步**。

**工程实现**：五维设计模板（形态×位置×动力学×膜×通量）将任何子框架分解为可填写的参数表。细胞标尺提供复杂度下界——做完一个子框架后，对标细胞的对应细胞器，差距量化（覆盖度、并行度、简并路径数）。不是"感觉够不够"——是参数表的对比。

| 失效模式 | 行业症状 | 本框架防护 |
|---------|---------|----------|
| 设计停滞——不知道"够不够" | 框架设计在哲学层反复迭代，无法进入工程实现 | 细胞标尺提供 L2 复杂度基准线 + cell-architecture/ 提供每个维度的量化参数 |

---

### 可评估性

**定义**：不需要"人判断系统好不好"。G(C) 量化跨域通用度。Protocol 7 自动扫描约束健康度。约束不变量可被自动验证。

**工程实现**：每个约束注册时声明 `domain_universality`。新域验证后自动更新。Protocol 7 的 CONSTRAINT_HEALTH_REPORT 定期输出（非自然语言，结构化）。约束不变量的数学形式可被 AST 分析或运行时断言检查。

| 失效模式 | 行业症状 | 本框架防护 |
|---------|---------|----------|
| 无法判断系统状态——一切靠人感觉 | "这个版本好像比上个版本好一点"——无量化指标 | G(C) + Protocol 7 + 约束不变量运行时断言。不是感性的"好/坏"——是可计算的"覆盖度/活力度/漂移度" |

---

### 可审计性

**定义**：每一步决策都可以追溯到具体约束、具体铁律、具体推理链。不是事后解释——是**事前可重放**。

**工程实现**：铁律 #4（形式化可重放）——`DecisionTrace` 完整快照。`@chain:` + `@invariant:` 标记代码约束来源。推理链双向追溯（代码↔链↔不变量）。Protocol 1 强制标注 `[来源: 公理推导/经验推测] [置信度: HIGH/MEDIUM/LOW]`。

| 失效模式 | 行业症状 | 本框架防护 |
|---------|---------|----------|
| 异常无法归因 → 调试靠猜 → 迭代停滞 | 生产事故复盘时无法确认"哪条规则导致了错误行为" | DecisionTrace 快照 → 追溯到触发 gate → gate 的阈值来自哪条铁律 → 铁律的推导来自哪条推理链 |

---

### 可溯源性

**定义**：不是"有文档"。是**代码 ↔ 链 ↔ 不变量 ↔ 公理**之间的双向追溯链不断裂。

**工程实现**：`@chain:` 指向推理链文件。链的 `produces_invariants:` 指向不变量。不变量的数学形式追溯到铁律。铁律追溯到公理。Protocol 5（遗忘预防）——当追溯链断裂时 AI 自动告警。

| 失效模式 | 行业症状 | 本框架防护 |
|---------|---------|----------|
| 追溯链断裂 → 不知道某参数为什么是这个值 → 不敢改 → 代码腐烂 | 六个月后回看代码，"这个 0.30 是哪来的？感觉是试出来的" | Protocol 5 自动检测断裂 + 12-反模式 #10（遗忘退行）标准诊断 |

---

### 可扩展性

**定义**：加新 Agent 不改框架代码。加新域不改内核代码。新能力 = 干细胞分裂——同一个 `kernel_step` 协议，不同的 Observer / 8 门阈值 / RL 槽位配置。

**工程实现**：同分异构——DNA（铁律 + ODE + 门控）不变，基因表达（配置参数）差异化。PluginRegistry 的槽位 + USB 模型——新能力注册而非新代码分支。三层体液池——新 Agent 通过浓度场自动加入工作组，不需要"注册到中央调度器"。

| 失效模式 | 行业症状 | 本框架防护 |
|---------|---------|----------|
| 扩展 = 改核心代码 → 每次扩展引入 bug | 新功能需要修改 Harness.step() 的分支逻辑 | 同分异构——不改内核。新 Agent = 新配置 + 新 Observer，kernel_step 不变 |

---

### 通用性

**定义**：同一套约束体系在三个完全不同物理定律的域中同时有效。不是"适配性强"——是**跨域不变性**。

**工程实现**：域通用度 G(C) 追踪每个约束在三个域中的状态。G(C) = 1.0 = 物理定律级别的正确。目标：三个域（Agent 对话 / 游戏引擎 / 具身智能）全部跑通后，G(C) 趋近 1.0 的约束集合 = 约束式工程论的实证验证。

| 失效模式 | 行业症状 | 本框架防护 |
|---------|---------|----------|
| 单域过拟合 → 换域全面崩溃 | 对话 Agent 框架无法迁移到物理控制场景——所有"经验"都是域特化的 | 域切换协议（11）强制跨域形式验证 + 参数分离。不是"调整参数"——是验证"形式在物理上是否存在于新域" |

## 三、性质间的耦合

性质不是独立列表——它们之间有依赖拓扑：

```
解耦性（膜边界）
    ├── 可扩展性（同分异构 = 膜系统复制 + 配置差异化）
    ├── 通用性（膜不变 = 跨域时形式不变, 只换膜上的蛋白）
    └── 可审计性（膜边界 = 信号追溯的起点和终点清晰）

可评估性（G(C) + Protocol 7）
    └── 倒逼内核（评估暴露盲区 → 盲区 = 迭代信号）

可溯源性（@chain: + @invariant:）
    └── 可审计性（追溯链完整的系统 = 可审计的。追溯链断裂 = 不可审计的反模式 #10）
```

**起点是解耦性**。膜是前提——没有膜，所有性质都在流沙上。

---

## 四、一句话

**这个框架不是 Agent 框架。它是约束环境生成器——不决策、不调度、不包装 LLM。只维持梯度、通量、膜边界。内核在这些约束构成的物理环境中存活、弛豫、演化。框架提供环境，内核提供决策，选择压力提供方向，跨域验证提供证据。L2 和 L3 不是设计出来的——是在这个环境中长出来的。**
