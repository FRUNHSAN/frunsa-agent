## 一、框架性质：不是 Agent 框架。是约束环境生成器。

全行业在造"让 LLM 更好用的壳"。这个项目在造**让约束能涌现的第一个细胞**。

| 维度 | 行业 Agent 框架 | 本框架 |
|------|----------------|--------|
| 决策者 | LLM ReAct loop | MPC 内核（ODE+Schmitt+Lipschitz） |
| 框架角色 | 调度器——"谁该调用什么工具" | **环境**——维持梯度、通量、膜边界 |
| LLM 地位 | CPU——决策核心 | **外设**——四条总线之一 |
| 安全 | Guardrail 关键词过滤 | Lipschitz 梯度有界——物理上不可能跳变 |
| 多 Agent | 中央调度器分配 | 三层体液池——信号梯度自组织，无调度器 |
| 演化 | 等模型更新 / 人工调 prompt | 多域选择压力 → 域约束跨域收敛 → L2/L3 |

**框架不决策。框架只维持梯度。内核在梯度中自行弛豫到吸引子。**

---

## 二、框架的目标

**L1 → L2 → L3：让约束从约束中涌现。**

| 层级 | 谁定义约束 | 约束是什么 | 当前状态 |
|------|----------|----------|---------|
| L0 | 你（设计者） | 7 条铁律 | ✅ V9.2c |
| L1 | 数据 | RL 策略槽位学到的 τ、η、受体亲和力 | 框架就绪，训练待做 |
| L2 | **约束本身** | 系统发现"现有约束不够"→ 生成新约束 | 目标——域约束跨域收敛时到达 |
| L3 | **约束的约束** | 系统修改生成约束的规则 | 渐近线 |

## 三、四条公理（宪法）

### 公理 1：约束先于形态（Constraint Precedes Morphology）

**定义**：定义数学不变量 → 推导稳态解空间 → 发现生物形态是该解空间的特例。不是"观察形态 → 抽象模式 → 实现功能"。

**判据**：设计子框架时无法写出**约束不变量**（Constraint Invariant）→ 禁止讨论"结构"或"接口"。没有不变量的结构是装饰。有不变量的结构才是器官。

**违反症状**："我觉得这个结构像线粒体所以应该有效"，但无法写出对应的不变量方程。讨论中反复出现"应该""感觉""参考了 XX 的设计"——没有一次追溯到公理推导链。

---

### 公理 2：环境先于智能（Environment Precedes Intelligence）

**定义**：构建具有物理约束的细胞质环境（三层体液池、浓度场、膜边界），让 MPC 内核在其中通过热力学必然性涌现出稳态行为。智能是在正确的约束环境中长出来的，不是被编程出来的。

**判据**：框架代码中不应包含任何"决策逻辑"（if-else / switch / prompt template）。框架只应包含"物理定律"（扩散方程、阈值函数、通量守恒）。框架在做决定 = 错。框架只在维持梯度 = 对。

**违反症状**：框架代码中出现 `if user_intent == "search" then route_to_search_agent`。或者 Harness 中有硬编码的策略分支。或者"根据经验，这个值设为 0.3 效果最好"——但可解释性追溯到数据，追溯不到公理。

---

### 公理 3：收敛即验证（Convergence Is Validation）

**定义**：先从控制论/信息论/非平衡热力学推导约束体系。再打开生物学教材。推导出的约束与生物结构重合 = 证据。不重合 = 推导有误或生物学特例。只有独立收敛的同构才具有工程合法性。

**判据**：每一个映射到工程中的生物学特征，必须附带一条不依赖生物学的推导链。链断了 = 审美偏好 → Protocol 1 标注 `[来源: 经验推测] [置信度: LOW]`。

**违反症状**：设计文档中直接引用生物学特征作为工程理由——"细胞有嵴所以 ODE 应该有层级结构"——但没有对应的数学推导段落。或同一段推理中同时出现"生物学里是这样"和"所以工程上应该这样"，中间缺失"为什么这个生物学特征在你的数学空间中是必然的"这一环。

---

### 公理 4：细胞标尺公理

**定义**：

1. 细胞是当前唯一同时满足【L2已验证】【自包含】【可量化】【多约束耦合】【40亿年选择压力】五个条件的系统。它是本项目复杂度的**下界标尺**，不是美学参考。
2. 对标**功能覆盖度**，不是组件数量。细胞有 60 种水解酶 ≠ 需要 60 个门。差距揭示的是盲区，不是待办清单。
3. **精度边界**：细胞是 L2 的完备标尺，是 L3 的不完整路标。L3 的规则自修改能力不可直接从细胞映射，必须由约束式工程论独立推导。
4. **可替换性**：若未来出现另一个同时满足上述五条件且可测量性更高的系统，标尺应迁移。当前无此系统。

**违反症状**：因"细胞有 X 个组件"就加 X 个同类组件，而没有验证功能覆盖度的等价性。或将细胞的 L3 级表观遗传机制（代际/发育时间尺度）直接映射为 Agent 的实时决策逻辑（毫秒/秒级）——时间尺度的不可通约被忽视。

## 四、为什么细胞是唯一可用的标尺——穷尽式排除法

| 候选系统 | L2？ | L3？ | 为什么不能当标尺 |
|---------|------|------|----------------|
| 大脑 | ✅ 突触可塑性 | ✅ 元学习 | 860 亿神经元，连接组未重建。对标都不知道在对标什么 |
| 免疫系统 | ✅ 适应性免疫 | ❓ | 依赖全身代谢。边界不清晰 |
| 生态系统 | ✅ 营养级联 | ❌ | 时间尺度太长（百年-千年），无法工程化 |
| 文明 | ✅ 制度涌现 | ✅ 宪法修正 | 几代人的时间尺度 |
| 语言 | ✅ 语法涌现 | ❓ | 无物理基底——纯信息 ≠ 物理约束 |
| **细胞** | ✅ | 🟡 部分 | **唯一五条件全满足 + 所有参数可量化** |

细胞是所有 L2/L3 系统的最小可测量单元。不是"一个参考"——是"底层基板"。

## 五、方法论完整闭环

```
约束式工程论（推导出形式）
        ↓
四条公理（验证形式正确性 + 违反症状检测）
        ↓
细胞工程标尺（验证复杂度充分性——L2 完备标尺 / L3 不完整路标）
        ↓
五维设计模板（形态×位置×动力学×膜×通量——实例化子框架）
        ↓
cell-architecture/ 原始档案（提供实例化的物理参数 + 置信度标签）
        ↓
框架实现（约束环境生成器——维持梯度，不做决策）
        ↓
新域部署（产生选择压力——验证域通用度 G(C)）
        ↓
倒逼内核迭代（域失效 = 约束盲区 = 内核需要暴露新能力）←────────┘
```

每一步的输入是上一步的输出。不可调换。没有捷径。

## 六、四块基石

| 基石 | 名称 | 功能 | 回答 |
|------|------|------|------|
| **宪法** | 公理 1-4 | 保证"不错"——排除伪约束、审美偏好、仿生学 cosplay | "这条路对不对？" |
| **刑法** | 铁律 7 条 | 保证"不塌"——状态空间不发散，Lipschitz 有界 | "内核会不会自毁？" |
| **标尺** | 细胞工程 | 保证"不够/不过"——复杂度下界、覆盖度基准、L2/L3 精度边界 | "离涌现还有多远？" |
| **档案** | cell-architecture/ | 保证"不瞎"——每次设计有量化物理参数可查 | "这个参数从哪来？什么置信度？" |
