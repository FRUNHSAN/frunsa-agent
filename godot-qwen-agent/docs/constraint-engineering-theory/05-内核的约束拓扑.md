# 05 — 内核的约束拓扑

**Last-verified-against-code**: `7e73374` (2026-07-04)
**预计阅读时间**: 15 分钟
**文笔配比**: 灵感 10 : 严谨 90 — 控制论教材式

---

7 条铁律不是在"保护"系统。它们是在定义状态空间的**能量景观**。

用精确的数学语言：铁律 #1-#7 合起来定义了状态流形 X ⊂ ℝ¹⁶ 上的一个 Finsler 度量——每一点 x ∈ X 处，允许的变化方向和速率是约束的。ODE 定义了该度量下的梯度流方向。Lipschitz 定义了梯度的最大范数。Schmitt 触发器定义了吸引子盆地之间的分水岭。

这和 AlphaFold 的能量函数 E(sequence, structure) 是同构的。AlphaFold 不画蛋白质的图纸——它定义能量景观，让分子自己找到最低能态。7 条铁律不规定 Agent 的行为——它们定义状态空间的能量景观，让行为从梯度流中涌现。

---

## 一、铁律的拓扑声明

每一条铁律不是"编码规范"或"安全规则"。它是状态空间的一个**几何声明**。

| # | 铁律 | 拓扑声明 | 几何意义 |
|---|------|---------|---------|
| 1 | 纯函数边界 | 状态空间是闭流形 | 没有"外部"的 I/O 注入未建模的自由度。边界条件完整 |
| 2 | 连续控制律 | 地形光滑 | 没有离散阶梯。梯度处处定义。水不能"跳跃"，只能沿梯度流 |
| 3 | 零自然语言 I/O | 语义噪声不进拓扑 | LLM 的 token 不确定性被隔离。内核只处理退相干后的经典状态 |
| 4 | 形式化可重放 | 路径可验证 | 相同初始条件 → 相同终态。不发散。吸引子存在且唯一 |
| 5 | 零动态分配 | 运行时拓扑不变 | 可能性空间的形状在编译时锁死。不出现运行时新增的维度 |
| 6 | Lipschitz 有界 | 地形无悬崖 | 最大坡度 ≤ 0.30。状态不可能在一帧内跳变。这是状态空间的"重力" |
| 7 | 信息损失可审计 | 拓扑同态 ≥ 50% | 连续→离散映射保留"相邻性"。不撕裂状态空间 |

## 二、与 AlphaFold 能量函数的同构性

这不是修辞。这是精确的结构对应：

| AlphaFold | MPC 微内核 |
|-----------|----------|
| E(sequence, structure) — 能量函数 | 7 条铁律 — 状态空间约束 |
| 疏水基必须朝内的物理约束 | `h(x) ≥ 0` 硬约束 |
| 氢键配对的距离约束 | Lipschitz `‖Δsv‖₂ ≤ 0.30` |
| 主链不能交叉的拓扑约束 | 8 门优先级链 |
| 梯度下降寻找最低能态 | ODE 梯度流驰豫到吸引子 |
| 最终结构 = 能量最小化 | `ControlFrame` = 约束下的最优决策 |

**AlphaFold 不需要知道"这个色氨酸应该折叠到 3.2Å 的位置"——它只需要知道"色氨酸不能折叠到 3.2Å 以外的位置"。你的内核同样不需要知道"Agent 应该说什么"——只需要知道"Agent 不能说什么"（forbidden_patterns）、"Agent 不能在什么状态做什么"（8 门路由）。**

## 三、完备度审计

拓扑白盒的声明不等于验证。以下是约束拓扑的完备度：

| 组件 | 拓扑声明 | 完备度 | 待验证 |
|------|---------|--------|--------|
| 7 条铁律 | 状态空间是有边界紧流形 | 90% | 形式化证明缺 |
| ODE 积分器 | 梯度流方向 | 85% | 参数待标定 [A1] |
| Lipschitz ‖Δsv‖ ≤ 0.30 | 梯度范数上限 | 已实现 | ε 值待域特化 [B3] |
| Schmitt 触发器 | 吸引子盆地分水岭 | 已实现 | 阈值置信度待补 [B1] |
| 8 门优先级链 | 拓扑的序结构 | 已实现 | — |
| 拓扑同态 H(ε) | 连续→离散保邻度 | 有度量 | 50%→65% 待提升 |
| Fisher 度量 G(x) [A2] | 地形弯曲度量 | **缺** | 需概率输出模型 |
| 纤维拓扑 [B2] | 吸引子连通性 | **缺** | Mapper 分析 |
| 范畴论合成 [D1] | 拼接不产生新裂缝 | **缺** | Para(Conv) 形式化 |
| 三层体液池 | 多 Agent 拓扑连接 | 已设计 | 待实现 |

## 四、从 LLM 的"量子不确定性"到内核的"经典世界"

你有一个精确的物理类比，一直没被明确写出来：

> LLM 的输出是"量子"的——你无法精确预测下一个 token。每次采样都是概率性的。但经过 Observer → Adapter 的"退相干"，它变成了 16 维的经典状态。内核只处理经典状态。

| 层级 | 物理对应 | 带宽 | 可靠性 |
|------|---------|------|--------|
| LLM token 概率分布 | 量子不确定性——每个 token 概率采样 | ∞，不可控 | 低 |
| Observer `ObservationResult` | 测量过程——波函数坍缩为 10 个标量 | 10 维 | 中 |
| Adapter `StateVector` | 退相干后的经典世界——16 个确定浮点数 | 16 维 | 高 |
| `kernel_step()` `ControlFrame` | 经典因果——3 种确定动作 | 3 种 | 确定 |

这就是为什么铁律 #3 说"内核零自然语言 I/O"——不是因为自然语言不好，是因为**自然语言在量子层，内核在经典层**。量子层的信息带宽无限但不可靠；经典层的信息带宽有限但可验证。

石棺的失败在于它试图在经典层用有限带宽控制无限维度的量子问题。真菌的成功在于它的"经典层"（基因组）只定义了拓扑约束，把量子层的细节留给涌现。

**你在做同样的事：LLM 的量子不确定性被隔离在外围，内核只在经典层做决策。经典层是拓扑白盒——完全透明、完全可审计、完全确定。**
