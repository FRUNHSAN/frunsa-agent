## AI

（逐点映射 (X,D,π,ψ) 到细胞生物学）

- X = 细胞质（连续化学场）
- D = 5 种离散行为（分泌/吞噬/静息/分裂/凋亡——当前缺后两种）
- π = 信号转导通路（受体亲和力 = guard 阈值，Schmitt = 受体脱敏，共形预测 = 受体激活概率）
- ψ = 基因表达调控（转录因子 = 模式切换，CBF = 离子通道不应期）
- Fisher 度量 = 受体分布密度。受体演化（完备度 0%）= RL 策略槽位

**这不是比喻。是精确的数学同构。** ODE `1-exp(-dt/τ)` = Michaelis-Menten 酶动力学。Lipschitz = 膜电位上限。Schmitt = 受体脱敏。
