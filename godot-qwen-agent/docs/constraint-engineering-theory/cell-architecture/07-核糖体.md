## 核心约束问题

### 约束不变量 (Constraint Invariant)

```
翻译精度——mRNA 解码错误率 < 10⁻⁴ (每104个密码子 < 1个错配)
∧ 肽键形成速率 ~10-20 aa/s (真核)——不能太快(错配概率↑)不能太慢(蛋白质需求)
∧ 核糖体组装——60S+40S亚基正确对接→80S 起始复合体
∧ [核糖体数量] ∝ [蛋白质合成需求] (增殖细胞 > 静止细胞)
```

### 失效模式 (Failure Mode)

```
翻译错误率 > 10⁻³ → 错误折叠蛋白积累
  [Y → 分子伴侣(BiP, Hsp70)缓冲——结合错误折叠蛋白→帮助重新折叠或降解]
  → 超过蛋白酶体/自噬降解容量→蛋白毒性应激
  → UPR激活(ER) + 热休克响应(胞质)
  → 持续→凋亡
```

## 物理结构

核糖核蛋白复合体。大亚基(60S——3种rRNA+~47种蛋白) + 小亚基(40S——1种rRNA+~33种蛋白)。总分子量 ~4.2 MDa(真核)。

**大小**：直径 ~25-30nm。

**三个tRNA结合位点**：A位(氨酰tRNA进入), P位(肽基tRNA), E位(去酰化tRNA退出)。

**肽基转移酶中心(PTC)**：60S大亚基 rRNA(28S)催化肽键形成——**核酶**, 不是蛋白质酶。

## 分子机制

### 翻译循环——延伸

```
1. 氨酰tRNA-GTP-EF1A 三元复合体→A位识别密码子(反密码子配对)
2. 正确配对→EF1A GTPase激活→EF1A-GDP释放→tRNA 进入A位
3. PTC 催化: P位肽基 转移到 A位氨酰基——肽键形成(肽链延长1aa)
4. EF2-GTP 结合→GTPase→易位: 核糖体沿mRNA移动1个密码子
   P位tRNA→E位(去酰化, 准备释放); A位tRNA→P位(带延伸肽链)
5. E位tRNA 释放; A位空出→循环回到步骤1
```

### 质量控制

**校对机制**：EF1A-GTP→tRNA进入→GTPase激活延迟(~ms)——给错配tRNA时间自发解离。正确配对tRNA滞留时间更长→GTPase概率↑。

**No-Go Decay**：核糖体在mRNA上停滞(二级结构障碍)→Dom34/Hbs1 招募→亚基分离→mRNA降解。

**Non-Stop Decay**：mRNA 缺少终止密码子→核糖体翻译到 polyA 尾→Ski7 结合→外切体降解 mRNA+释放核糖体。

### 组装——核仁

```
rRNA 转录(Pol I——47S pre-rRNA)→加工(切割+修饰→28S, 18S, 5.8S rRNA)
  + 核糖体蛋白(RP)结合→60S+40S 前体亚基→核仁→核质→NPC 出口→胞质成熟
```

## 与其它细胞器的物理连接

| 连接 | 连接的细胞器 | 运输的分子 | 方向 | 关键蛋白 |
|------|------------|----------|------|---------|

| 游离核糖体 | 胞质 | 完成合成后释放到胞质 | Rib→Cytosol | — |
