## 核心约束问题

### 约束不变量 (Constraint Invariant)

```
ΔΨ_m ≥ 150mV（内膜跨膜电位——质子动势的电场分量）
∧ ΔpH ≈ 0.5-1.0（内膜跨膜pH梯度——质子动势的化学分量）
∧ [ATP]/[ADP] > 10（胞质能量电荷——磷酸化势）
∧ ROS产生速率 < 清除速率（氧化还原稳态）
∧ 内膜通透性 ≈ 0（除ATP合酶和转运蛋白外, 内膜对质子不通透）
```

总质子动势 p.m.f. = ΔΨ_m − (2.303RT/F)·ΔpH ≈ 180-220mV。

### 失效模式 (Failure Mode)

```
ΔΨ_m < 120mV（触发事件——质子泄漏 > 电子传递链泵出能力）
[Y → 解偶联剂(UCP1)可暂时恢复质子梯度; 基质pH缓冲]
  → ATP合酶反转——消耗ATP泵质子（秒级）
  [Y → 抑制ATP合酶(寡霉素)可阻止ATP消耗]
  → 胞质[ATP] < 1mM [t₁/₂ ≈ 3min]
  [N → 所有ATP依赖泵停转——SERCA, PMCA, Na⁺/K⁺-ATPase。不可逆点]
  → 胞质[Ca²⁺]持续上升（分级-小时）
  → [Ca²⁺]_mito > 10μM → mPTP开放（小时级）
  [N → MOMP一旦发生，cytochrome c释放后凋亡不可逆]
  → cytochrome c → Apaf-1 → apoptosome → caspase-9 → caspase-3/7 → 凋亡
```

## 约束推导：为什么线粒体必须有解偶联蛋白？

1. **物理约束**：质子梯度 ΔΨ_m 是 ATP 合成的驱动力。但 ETC 通量与 ATP 消耗速率不总是匹配——ATP 消耗速率由胞质需求（肌肉收缩、离子泵、蛋白合成）决定，ETC 通量由底物可用性（NADH、FADH₂）决定。两者无直接耦合机制。当 ATP 需求低而 ETC 通量高时，质子被持续泵入膜间隙，ΔΨ_m 会超过 220mV。

2. **热力学后果**：过高的 ΔΨ_m 使复合体 I 和 III 的电子泄漏率呈指数上升。泄漏的电子直接将 O₂ 还原为超氧阴离子（O₂⁻）→ SOD 歧化为 H₂O₂ → Fenton 反应产生 ·OH → 膜脂过氧化、mtDNA 损伤、铁硫簇破坏。ROS 产生率与 ΔΨ_m 呈超线性关系——每次 ΔΨ_m 超过安全阈值，产生的不是"多一点损伤"，而是"指数增长的氧化爆发"。

3. **唯一稳态解**：必须存在一个**不耦合 ATP 合成的质子回流通道**，在 ΔΨ_m 超过 ~220mV 时自动导通，耗散过量的质子梯度。这就是 UCP（解偶联蛋白，uncoupling protein）。UCP 为 H⁺ 提供了 ATP 合酶之外的返回路径——质子不是"浪费了"，而是被转化为热量释放。这不是效率损失——这是**防止热力学灾难的压力释放阀**。没有 UCP 的系统在 ETC 与 ATP 消耗速率不匹配时会自毁。

4. **调控必然性**：UCP 的导通必须受 ΔΨ_m 本身或 ROS 浓度调控——正反馈。ΔΨ_m 越高 → UCP 导通越多 → 梯度耗散越多 → ΔΨ_m 回落。ROS 越高 → UCP 激活（通过脂质过氧化产物 4-HNE 修饰 UCP）→ ΔΨ_m 降低 → ROS 产生下降。如果 UCP 不受 ΔΨ_m/ROS 调控——要么永远关闭（失去保护，ROS 爆炸），要么永远开启（ATP 合成完全解耦，能量枯竭）。闸门的开启阈值必须精确匹配 ΔΨ_m 的安全上界。

## 物理结构

**膜系统**：双膜（外膜 OMM + 内膜 IMM）。膜间隙在中间。内膜内折形成嵴(cristae)以增加表面积。

| 结构 | 特征 |
|------|------|
| 外膜 (OMM) | 平滑。含 VDAC(电压依赖性阴离子通道)——允许<5kDa分子自由通过。线粒体外膜通透化(MOMP)是凋亡的不可逆点 |
| 膜间隙 | 含 cytochrome c（正常时在嵴内）。质子浓度高(H⁺被ETC泵入)。宽度 ~20nm |
| 内膜 (IMM) | 高度折叠(嵴)。对离子/质子不通透(除非有转运蛋白)。含电子传递链复合体I-IV + ATP合酶(F₁F₀)。含心磷脂(cardiolipin)——与凋亡相关 |
| 基质 | 含 mtDNA(环状, ~16.6kb, 37个基因)。含核糖体(70S型, 与细菌同源)。TCA循环酶 |

```
外膜 (OMM)
  │ VDAC (通透 <5kDa)
  │
膜间隙 [H⁺ 高浓度] [cytochrome c]
  │
内膜 (IMM)——嵴
  │ CI      CII     CIII    CIV     CV(ATP合酶)
  │ NADH→Q  FADH₂→Q  Q→cyt c  cyt c→O₂  ADP+Pi→ATP
  │    ↓ 质子泵出 (I, III, IV) → 膜间隙[H⁺]↑  ↓
  │         ←── 质子回流通过 ATP合酶 ←──
  │
基质 [TCA循环] [mtDNA] [核糖体] [Ca²⁺ 缓冲]
```

**数量/细胞**：数百到数千（取决于细胞能量需求。肝细胞 ~1000-2000。心肌细胞 ~5000-8000）。

**尺寸**：长约 2-8μm，直径约 0.5-1.0μm。直径接近细菌大小（内共生起源）。

**动态行为**：**持续分裂（fission）和融合（fusion）**——不是静态细胞器。融合修复损伤（功能互补）。分裂隔离损伤部分→线粒体自噬。

## 分子机制

### 电子传递链 (ETC) & 氧化磷酸化 (OXPHOS)

```
复合体I (NADH脱氢酶)
  输入: NADH (来自TCA循环), Q (泛醌)
  催化: NADH + Q + 5H⁺_matrix → NAD⁺ + QH₂ + 4H⁺_IMS
  输出: QH₂, 泵出4个质子

复合体II (琥珀酸脱氢酶——也是TCA循环酶)
  输入: FADH₂ (来自琥珀酸氧化), Q
  催化: 琥珀酸 + Q → 延胡索酸 + QH₂
  输出: QH₂ (不泵质子——CII贡献电子但不贡献质子动势)

复合体III (细胞色素 bc1)
  输入: QH₂, 2 cyt c(ox)
  催化: QH₂ + 2 cyt c(ox) + 2H⁺_matrix → Q + 2 cyt c(red) + 4H⁺_IMS
  (Q循环——每1个QH₂泵出4个质子)
  输出: cyt c(red), pH⁺_IMS

复合体IV (细胞色素 c 氧化酶)
  输入: 4 cyt c(red), O₂, 8H⁺_matrix
  催化: 4 cyt c(red) + O₂ + 8H⁺_matrix → 4 cyt c(ox) + 2H₂O + 4H⁺_IMS
  输出: 2H₂O (氧的最终电子受体)

ATP合酶 (复合体V, F₁F₀ ATPase)
  输入: ADP + Pi (基质), 质子动势(p.m.f. ~180mV)
  催化: 3-4H⁺ 回流 → 旋转催化 → 1 ATP 合成
  输出: ATP (释放到基质→被ANT运出)
  反转(ΔΨ_m < 120mV时): 消耗ATP泵质子——维持膜电位
```

**总ATP产量**：1 NADH → ~2.5 ATP。1 FADH₂ → ~1.5 ATP。1 葡萄糖(完全氧化) → ~26-28 ATP（取决于胞质NADH的穿梭方式）。

### TCA 循环 (基质)

```
乙酰CoA + 草酰乙酸 → 柠檬酸 (柠檬酸合酶)
  → 异柠檬酸 → α-酮戊二酸 (异柠檬酸脱氢酶——产生 NADH)
  → 琥珀酰CoA → 琥珀酸 (琥珀酰CoA合成酶——产生 GTP)
  → 延胡索酸 → 苹果酸 → 草酰乙酸 (产生 FADH₂ + NADH)
```

### 线粒体 Ca²⁺ 处理

```
Ca²⁺ 进入: MCU (线粒体钙单向转运体)
  - 低亲和力(Kd ~20-30μM)——但MAMs处局部[Ca²⁺]可达>100μM
  - 依赖ΔΨ_m驱动(带正电的Ca²⁺被负膜电位吸引)
  - 调控: MICU1/MICU2(低[Ca²⁺]时关闭MCU——防止静息时Ca²⁺泄漏)

Ca²⁺ 效应(基质):
  - 低[Ca²⁺] (0.1-1μM): 激活PDH(丙酮酸脱氢酶) + ICDH + α-KGDH——TCA循环加速
  - 高[Ca²⁺] (>10μM): 触发mPTP开放——通透性转换孔
    mPTP: 非选择性孔(>1.5kDa分子可过)→ΔΨ_m 坍缩→cytochrome c 释放→凋亡

Ca²⁺ 排出: NCLX (Na⁺/Ca²⁺ 交换体——利用Na⁺梯度将Ca²⁺泵出)
```

### 线粒体动力学 (Fission/Fusion)

```
融合 (Fusion):
  - OMM融合: MFN1/MFN2 (Mitofusin)
  - IMM融合: OPA1 (Optic Atrophy 1)
  - 功能: 损伤稀释——融合后功能互补(mtDNA, 代谢物交换)

分裂 (Fission):
  - DRP1(DLP1)被MFF/FIS1/MiD49/51招募到线粒体表面
  - DRP1寡聚化形成螺旋→GTP酶活性→收缩→切割
  - 功能: 隔离损伤——分裂后受损子线粒体ΔΨ_m低→PINK1/Parkin标记→线粒体自噬
```

### 逆行信号 (Mitochondrial Retrograde Signaling)

```
应激信号 → 核:

OMA1-DELE1-HRI 通路:
  线粒体应激(ΔΨ_m↓, 蛋白输入障碍)→OMA1蛋白酶激活
  → 切割 DELE1→DELE1释放到胞质→入核
  → DELE1结合并激活 HRI(eIF2α激酶)
  → eIF2α磷酸化→全局翻译抑制+ATF4选择性翻译
  → ATF4→CHOP(GADD153), GADD34

代谢物信号:
  TCA循环中断→α-KG↓→依赖α-KG的双加氧酶(组蛋白去甲基化酶, TET)活性↓
  → H3K27me3↑(组蛋白甲基化积累)→基因表达程序改变
  乙酰CoA↑(脂质代谢)→组蛋白乙酰化↑→全局染色质松弛
```
