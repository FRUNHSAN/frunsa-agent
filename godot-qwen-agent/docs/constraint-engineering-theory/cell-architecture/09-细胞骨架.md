## 核心约束问题

### 约束不变量 (Constraint Invariant)

```
微管——持续动态不稳定性: 聚合速率 > 解聚速率（净生长），或反之
∧ [GTP-微管蛋白] > 临界浓度（~10-20μM——聚合靶点）
∧ 肌动蛋白——ATP-肌动蛋白聚合临界浓度 ~0.1μM(+端) vs 0.6μM(−端)（踏板式 treadmilling）
∧ 机械张力——细胞骨架重组以平衡外力（力学稳态 ~nN/μm² 量级）
```

### 失效模式 (Failure Mode)

```
微管完全解聚(如秋水仙碱处理):
  → 高尔基碎裂——依赖于微管的囊泡运输中断
  → ER 从外周回缩——ER-微管滑行(kinesin驱动)失效
  → 有丝分裂停止(无纺锤体)
  [Y → 洗脱药物后微管可重新聚合——但长时间后细胞退出周期→凋亡]
```

## 物理结构

三套独立的纤维系统：

| 纤维 | 直径 | 主要蛋白 | 极性 | 动态性 |
|------|------|---------|------|--------|
| **微管(MT)** | 25nm(外径) | α/β-微管蛋白异源二聚体→13原丝→空心管 | +(快长端), -(慢端, 常锚定在中心体) | 动态不稳定性——持续随机在生长和缩短间切换。t₁/₂ ~5-10min |
| **微丝(Actin)** | 7-9nm | G-肌动蛋白→F-肌动蛋白(双链螺旋) | +(barbed端), −(pointed端) | treadmilling——+端净聚合, −端净解聚。t₁/₂ ~30s-几min |
| **中间纤维(IF)** | 10nm | 组织特异性(角蛋白/波形蛋白/核纤层蛋白/神经丝蛋白) | 无极性——两端相同 | 稳定——比MT和actin都稳定。t₁/₂ ~几h-几天 |

## 分子机制

### 动力蛋白——沿纤维定向运输

| 马达 | 纤维 | 方向 | 速度 | 货物 |
|------|------|------|------|------|
| **驱动蛋白(Kinesin-1)** | MT | (+)端(向外周) | ~0.5-1.0 μm/s | 囊泡, 线粒体, ER, mRNA |
| **胞质动力蛋白(Dynein)** | MT | (−)端(向中心体/核) | ~0.5-1.0 μm/s | 囊泡, 高尔基, 内吞体, 线粒体 |
| **肌球蛋白 V(Myosin V)** | Actin | (+)端 | ~0.2-0.4 μm/s | 囊泡(短距), 细胞器锚定 |
| **肌球蛋白 II(Myosin II)** | Actin | — | — | 收缩——应力纤维, 胞质分裂环 |

### 微管动态不稳定性

```
GTP-微管蛋白结合到(+)端→GTP帽稳定→持续生长
  → 偶然GTP水解(GDP-微管蛋白)晚于微管蛋白添加→GTP帽持续
  → 如果GTP帽消失(GDP-微管蛋白暴露)→protofilaments弯曲→"灾难性"解聚
  → 解聚→GTP-微管蛋白重新结合→"救援"→重新生长
```

### 力学信号传导

```
整合素(ECM结合)→粘着斑(FA)→应力纤维(actin+myosin II)
  → 牵张力→talin 展开→vinculin 结合→加固粘着斑
  → 持续张力→YAP/TAZ 核定位(转录共激活因子——机械信号→基因表达)
  → 张力解除→YAP/TAZ 磷酸化→胞质滞留
```
