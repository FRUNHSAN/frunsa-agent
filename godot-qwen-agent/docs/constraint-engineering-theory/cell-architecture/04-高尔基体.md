## 核心约束问题

### 约束不变量 (Constraint Invariant)

```
顺面(cis)→中间(medial)→反面(trans)——蛋白质沿堆叠单向流动
∧ 修饰酶保持正确的顺-反分布（COPI 逆向运输回收逃逸酶）
∧ cisternal maturation——每个水槽从cis成熟到trans（不是蛋白质在移动，是水槽在成熟）
```

### 失效模式 (Failure Mode)

```
高尔基碎裂(微管解聚/药物处理)
  → 蛋白质修饰停止——糖基化中断→蛋白质功能异常→分泌阻断
  → 分散小堆叠分散到ER附近→部分功能维持(但效率↓)
  [Y → 去除药物后微管重新聚合→高尔基重新组装]
```

## 物理结构

堆叠的扁平膜囊(水槽, cisternae)。典型 4-8 层/堆叠。多个堆叠通过膜管连接成高尔基带。

**区室**：cis-Golgi(ER侧, COPII到达) → medial-Golgi → trans-Golgi(TGN, 面向质膜)。

**尺寸**：单个水槽厚 ~15-20nm, 堆叠高 ~1-2μm。整个高尔基定位在微管组织中心(MTOC)附近——依赖于微管。

---

## 分子机制

### 蛋白质运输——cisternal maturation 模型

COPII囊泡(ER→cis-Golgi)→货物蛋白进入cis水槽→水槽成熟(酶组成改变——COPI回收早期酶)→最终到达TGN→分泌囊泡出芽。

**COPI**：回收逃逸的ER蛋白(KDEL受体→结合KDEL序列的ER蛋白)→以及高尔基酶的顺面定位。

### 糖基化——主要修饰

N-糖基化：ER 中预装配的高甘露糖→高尔基中修剪+添加(GlcNAc, Gal, Neu5Ac)→复合型 N-糖链。
O-糖基化(GalNAc-Ser/Thr)主要在 cis-Golgi。
