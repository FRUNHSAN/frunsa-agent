## 核心约束问题

### 约束不变量 (Constraint Invariant)

```
核膜完整性（双层膜, 核孔复合体 NPC 控制通透）
∧ DNA 不离开核（转录在核内, 翻译在胞质——真核生物的根本创新）
∧ 核质[转录因子] = f(胞质信号)（核不自产转录因子——外部信号驱动基因表达）
∧ [NPC 运输速率] > [mRNA 产生速率]（信息不积压）
∧ [染色质可及性] ∈ [0,1]（异染色质=沉默, 常染色质=可转录——表观遗传约束）
```

### 失效模式 (Failure Mode)

```
核膜破裂 → 核质内容物与胞质混合 → 混合后: 核酸酶激活→DNA降解; 
  胞质蛋白错误进入核→转录异常; 核内结构蛋白(lamins)暴露→被caspase切割
  [Y → 局部破裂可由 ESCRT-III 修复——小破损]
  [N → 大面积破裂 → 不可逆。是凋亡的执行阶段之一]
```

## 物理结构

双层核膜(外膜+内膜, 中间腔与ER连通)。核孔复合体(NPC)跨越双膜——被动扩散(<40kDa)和主动运输(>40kDa)。

**染色质**：DNA 包裹组蛋白八聚体→核小体→30nm纤维→拓扑相关结构域(TADs)→染色体区域。异染色质(致密, 沉默) vs 常染色质(松散, 可转录)。

**核仁**：无膜细胞器——液-液相分离形成。rRNA 转录+核糖体亚基组装。**浓度依赖性凝聚。**

**核纤层(nuclear lamina)**：核膜内面的中间纤维网络(核纤层蛋白 A/C, B)。提供结构支撑 + 染色质锚定点。

## 分子机制

### NPC 运输

RanGTP-RanGDP 梯度驱动：核内 RanGTP 高(因 RanGEF/RCC1 定位于核)。胞质 RanGDP 高(因 RanGAP 定位于胞质)。

核输入：Importin-α 识别货物 NLS→Importin-β 介导 NPC 运输→RanGTP 结合 Importin-β→货物释放入核。
核输出：Exportin(Crm1) 识别货物 NES + RanGTP→NPC 运输→胞质 RanGAP 水解 RanGTP→货物释放。

### 转录调控

转录因子(TF)在胞质中被信号通路激活(磷酸化/去抑制/核定位信号暴露)→入核→结合靶基因启动子/增强子→招募 RNA Pol II→转录起始。

**转录工厂**：~10-30 个活跃 Pol II 聚集在转录工厂(核内离散位点)，而非均匀分散。功能：集中相关基因共转录——效率。

### 表观遗传标记

| 修饰类型 | 位置 | 效应 | 可逆性 |
|---------|------|------|--------|
| DNA 甲基化 | CpG 岛 | 转录抑制(MeCP2 结合→染色质压缩) | 慢(需 TET 氧化去甲基化) |
| H3K4me3 | 启动子 | 转录激活 | 快(LSD1 去甲基化) |
| H3K27me3 | 增强子/启动子 | 转录抑制(Polycomb) | 慢 |
| H3K9ac | 启动子/增强子 | 转录激活(乙酰基中和正电荷→DNA松弛) | 快(HDAC 去乙酰化) |
| H3K27ac | 增强子(活性标记) | 超级增强子形成 | 快 |

## 关键参数表

| 参数 | 值 | 置信度 | 来源 |
|------|-----|--------|------|
| 核直径 | ~6-10μm | HIGH | 光学显微镜 |
| NPC 密度 | ~2-5 NPC/μm² (分裂间期) | MEDIUM | 冷冻电镜断层扫描 |
| NPC 被动扩散截止 | ~40kDa(球形蛋白) | HIGH | 注射荧光标记葡聚糖 |
| NPC 主动运输速率 | ~100-1000 分子/NPC/s | MEDIUM | 单分子荧光 |
| RanGTP 梯度(核/胞质比) | ~200:1 (RCC1 in, RanGAP out) | MEDIUM | FRET探针 |
| 核小体间距 | ~200bp (147bp 包裹 + ~50bp 连接DNA) | HIGH | MNase消化 |
| CpG 甲基化 基因组比例 | ~70-80% (正常体细胞) | HIGH | 亚硫酸氢盐测序 |
