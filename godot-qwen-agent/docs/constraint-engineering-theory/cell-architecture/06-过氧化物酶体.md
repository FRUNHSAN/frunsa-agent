# 06 — 过氧化物酶体

**许可**：CC BY-ND 4.0

---

## 核心约束问题

### 约束不变量 (Constraint Invariant)

```
[H₂O₂] 产生速率 ≤ 过氧化氢酶清除速率（ROS 不泄漏到胞质）
∧ pH ≈ 8.0（碱性——利于氧化酶活性）
∧ 膜对 NAD⁺/NADH 不通透（氧化还原隔离——和溶酶体的 pH 隔离同构但不同机制）
```

### 失效模式 (Failure Mode)

```
过氧化氢酶功能障碍 → H₂O₂ 泄漏
  → 胞质[ROS]↑ → 脂质过氧化 → 膜损伤 → 铁死亡(ferroptosis)可能触发
  [Y → 谷胱甘肽过氧化物酶(GPx)可部分补偿]
  [N → 重度氧化应激——线粒体+溶酶体同时受损→坏死]
```

---

## 物理结构

单层膜。直径 ~0.1-1.0μm。数量/细胞 ~100-1000(肝细胞最多——解毒)。从 ER 出芽或通过分裂繁殖。

含：氧化酶(产生 H₂O₂), 过氧化氢酶(分解 H₂O₂), β-氧化酶系(降解超长链脂肪酸)。不含 DNA——所有蛋白从胞质输入(PTS1/PTS2 信号)。

---

## 分子机制

### ROS 代谢

```
长链/支链脂肪酸→FAD-氧化酶→FADH₂→O₂→H₂O₂(产生ROS)
  → 过氧化氢酶: 2H₂O₂→2H₂O+O₂(速率极快——kcat ~10⁶ s⁻¹)
```

### 脂肪酸 β-氧化

超长链脂肪酸(VLCFA, >C22)→β-氧化→中链脂肪酸→线粒体继续氧化。

| 参数 | 值 | 置信度 | 来源 |
|------|-----|--------|------|
| 过氧化氢酶 kcat | ~10⁶ s⁻¹(最高效的酶之一) | HIGH | 体外酶活 |
