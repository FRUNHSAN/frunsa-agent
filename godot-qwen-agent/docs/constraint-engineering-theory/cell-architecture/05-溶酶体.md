## 核心约束问题

### 约束不变量 (Constraint Invariant)

```
pH_lumen ∈ [4.5, 5.0]（V-ATPase 维持的质子梯度——H⁺_lumen/H⁺_cytosol ≈ 1000）
∧ 溶酶体膜完整性——cathepsin 等水解酶不得泄漏到胞质（pH 7.2 下仍有残余活性）
∧ [水解酶] > [待降解底物]（降解容量不饱和——否则底物积累=贮积症）
∧ mTORC1 在膜表面的定位 ⇔ 营养感知开启（氨基酸充足→mTORC1 锚定→TFEB 磷酸化→被滞留胞质）
```

### 失效模式 (Failure Mode)

```
轻度 LMP（个别溶酶体膜穿孔）
  [Y → ESCRT 修复膜穿孔; 溶酶体自噬(lysophagy)清除受损溶酶体]
  → cathepsin B/D 泄漏到胞质（浓度低, 可被 cystatin 抑制）
  [Y → 内源性抑制剂(cystatins, serpins)缓冲低浓度泄漏]
  
中度 LMP
  → cathepsin 浓度超过抑制剂缓冲容量（分级-小时）
  → cathepsin 切割 BID → tBid → MOMP（凋亡激活）
  [Y → 泛凋亡抑制剂可暂时阻断]
  
重度 LMP（全溶酶体池 >50% 通透化）
  → 大量水解酶释放→随机蛋白降解→胞质酸化
  → 溶酶体内容物(Fe²⁺, ROS)释放→脂质过氧化→铁死亡(ferroptosis)触发
  [N → 不可逆——细胞自溶]
```

## 物理结构

单层膜——有别于其它细胞器(不连续双层)。膜含高糖基化蛋白(LAMP1, LAMP2)在腔面形成糖萼——保护溶酶体膜不被自身水解酶消化。

内腔：含 ~60 种酸性水解酶(蛋白酶, 脂酶, 核酸酶, 糖苷酶)。最适 pH 4.5-5.0。pH 由 V-ATPase(质子泵, 消耗ATP)维持。

**数量/细胞**：~50-1000(取决于细胞类型)。**非均匀分布**——部分定位在核周(mTORC1活性高), 部分在外周(与自噬体融合)。

## 分子机制

### V-ATPase——质子泵

```
输入: ATP(胞质), H⁺(胞质)
催化: ATP水解驱动2H⁺泵入溶酶体腔(V₀ 旋转域+c-ring)。旋转催化——每次360°旋转泵出~6-10个H⁺
输出: H⁺_lumen↑(维持pH 4.5-5.0), ADP + Pi
```

V-ATPase 可逆——但生理条件下不反转(ΔpH 太大, 反转需要 ΔG > 40 kJ/mol)。

### mTORC1 复合体——营养感知枢纽

```
mTORC1 定位依赖:
  氨基酸充足→Rag GTPase (RagA/B-GTP, RagC/D-GDP)→将 mTORC1 招募到溶酶体表面
  → mTORC1 与 Rheb-GTP(Rheb 定位于溶酶体膜)结合→激酶活性开启
  → 磷酸化下游靶点: S6K(蛋白翻译), 4E-BP(翻译起始), TFEB(转录因子——此时被磷酸化留胞质)

  氨基酸匮乏→Rag 构象转换→mTORC1 从溶酶体解离→失活
  → TFEB 去磷酸化→入核→激活 CLEAR 基因网络(溶酶体生物合成+自噬)
```

### 自噬流 (Autophagic Flux)

```
宏自噬: 自噬体(双层膜,包裹待降解物)→与溶酶体融合→自噬溶酶体→降解
线粒体自噬(Mitophagy): PINK1 稳定在去极化线粒体OMM→招募 Parkin→泛素化OMM蛋白→p62/LC3 识别→自噬体包裹
分子伴侣介导自噬(CMA): Hsc70 识别 KFERQ 基序→LAMP2A 转位→底物去折叠→入腔降解
```

### 溶酶体胞吐 (Lysosomal Exocytosis)

```
溶酶体+质膜融合→内容物释放到胞外
  触发: 局部[Ca²⁺]↑→Synaptotagmin VII→SNARE介导融合
  功能: 膜修复(捐献膜修补穿孔), 分泌(免疫细胞释放细胞毒性颗粒)
```

## 关键参数表

| 参数 | 值 | 置信度 | 来源 |
|------|-----|--------|------|
| 腔 pH | 4.5-5.0 | HIGH | pH敏感荧光探针 |
| V-ATPase H⁺泵出 | ~2H⁺/ATP | MEDIUM | 旋转催化模型 |
| mTORC1 Kd (Rheb-GTP) | ~0.1-1μM | LOW | 体外结合测定 |
| 溶酶体直径 | 0.1-1.2μm | MEDIUM | 电子显微镜 |
| 单细胞溶酶体数 | ~50-1000 | MEDIUM | 荧光标记计数 |
| Cathepsin B 最适pH | 5.0-6.0(但在 pH 7.2 有残余活性~10%) | MEDIUM | 体外酶活测定 |
| 自噬体融合速率 | ~1-5 融合/cell/hr(基础, 可被 mTORC1 抑制上调 10×) | LOW | 活细胞成像 |
