## 核心约束问题

### 约束不变量 (Constraint Invariant)

```
[Ca²⁺]_ER ≈ 500μM (总, 游离 ~50-100μM) ∧ [Ca²⁺]_cytosol ≈ 100nM → 梯度 ≈10³-10⁴
∧ [未折叠蛋白] < UPR 激活阈值（BiP 的缓冲容量决定）
∧ SERCA 泵活性 > ER Ca²⁺ 泄漏速率（静息时净摄入为正）
∧ 氧化还原环境——氧化(利于二硫键形成), E_GSH/GSSG ≈ −210mV（高氧化）
```

### 失效模式 (Failure Mode)

```
[未折叠蛋白] > BiP 缓冲容量（分级-小时级）
  [Y → UPR 三传感器(IRE1, PERK, ATF6)激活——暂停翻译、上调伴侣、增强ERAD——买时间]
  → 适应期: 全局翻译暂停(PERK-eIF2α), 伴侣↑(XBP1s), ERAD↑
  → 如果UPR失败（应激持续）→ ATF4→CHOP 累积（小时-天级）
  → CHOP↑→BCL-2↓+BIM↑（天级）
  [Y → GADD34 去磷酸化 eIF2α 恢复翻译——但若CHOP已到阈值, 恢复翻译反而加速凋亡蛋白合成]
  → BCL-2 家族失衡→BAX/BAK 寡聚化→MOMP（不可逆）
  [N → MOMP后凋亡通路激活，不可逆]
```

## 物理结构

单层连续膜网络——占细胞总膜面积 ~50%。与核外膜连续。

- **粗面ER (rER)**：附着核糖体。蛋白质合成+共翻译转运入ER。
- **滑面ER (sER)**：无核糖体。Ca²⁺ 储存+脂质合成+解毒(CYP450)。
- **ER出口位点 (ERES)**：COPII囊泡形成处。ER-高尔基运输起点。

## 分子机制

### 蛋白质折叠QC

```
新生肽链→Sec61转位子入ER→BiP(分子伴侣)结合→防止聚集
  → 寡糖基转移酶(OST)→N-糖基化→calnexin/calreticulin循环→辅助折叠
  → PDI(二硫键异构酶)→催化二硫键形成和重排

折叠失败→ERAD(ER相关降解): 错误折叠蛋白→逆向转位到胞质→泛素化→蛋白酶体降解
  或→ER自噬(ER-phagy): 大片ER膜+错误折叠蛋白→自噬降解
```

### Ca²⁺ 稳态

```
Ca²⁺ 进入 ER: SERCA (肌质/内质网Ca²⁺-ATPase)——每泵2个Ca²⁺消耗1个ATP
  SERCA亚型: SERCA2b(广泛), SERCA1(骨骼肌——高速型)

Ca²⁺ 释放: IP3R (IP3门控——PLC→PIP2→IP3→ER释放Ca²⁺)
  RyR (Ryanodine受体——Ca²⁺诱导Ca²⁺释放 CICR, 主要在肌肉)

泄漏: 被动Ca²⁺泄漏(机制未完全阐明——可能通过Sec61或TMCO1)
```

### UPR 三传感器

| 传感器 | 静息 | 激活 | 输出 |
|--------|------|------|------|
| IRE1 | BiP 结合→单体 | 未折叠蛋白→BiP 解离→IRE1 二聚化/自磷酸化→XBP1 mRNA切割 | XBP1s→分子伴侣↑, ERAD↑ |
| PERK | BiP 结合→单体 | 同↑→PERK 二聚化/自磷酸化→eIF2α 磷酸化 | 全局翻译↓, ATF4↑→CHOP, GADD34 |
| ATF6 | BiP 结合→ER滞留 | 未折叠蛋白→BiP 解离→ATF6→COPII→高尔基→被S1P/S2P切割→释放ATF6f | ATF6f→XBP1(放大), 分子伴侣 |

## 约束推导 1：为什么 UPR 必须有三条结构不同的传感器？

1. **检测问题**：未折叠蛋白的浓度变化是连续、缓慢、嘈杂的。ER 腔内没有"折叠状态传感器"可以直接读取每个蛋白的构象——只能通过间接信号（BiP 从传感器上解离）推断应激水平。BiP 是一个通用的分子伴侣——它结合疏水暴露区，而非特异地识别"折叠失败的蛋白"。

2. **信噪比约束**：单一传感器的误报率不可接受。BiP 可能因以下原因解离——pH 波动（代谢切换导致 ER 腔酸化）、Ca²⁺ 浓度变化（IP3R 开放后 ER 腔内[Ca²⁺]短暂下降）、翻译爆发（新合成蛋白短时间内涌入 ER 超过 BiP 结合容量）。这些都不是真正的未折叠蛋白危机——但单传感器无法区分。将 pH 波动误判为 UPR → 触发不必要的全局翻译暂停 → 细胞在无危机时停止蛋白合成 → 功能自废。

3. **信息论必然性**：三个结构不同的传感器——IRE1（具有 RNase 结构域，切割 XBP1 mRNA）、PERK（具有激酶结构域，磷酸化 eIF2α）、ATF6（是转录因子前体，被高尔基蛋白酶切割后释放活性域）——对同一输入（BiP 解离）有：
   - **不同激活阈值**：IRE1 最先响应（低阈值），PERK 次之，ATF6 最慢
   - **不同响应时间常数**：PERK 通过磷酸化在分钟内暂停全局翻译，IRE1 通过 mRNA 切割在数十分钟内产生 XBP1s，ATF6 通过高尔基转运 + 蛋白酶切割在小时级响应
   - **不同下游输出**：暂停翻译、上调分子伴侣、扩大 ER 容量
   - 三者同时误报的概率 = 各自误报率的乘积。这不是冗余（备份副本）——这是**交叉验证**。结构差异 = 失效模式独立 = 系统鲁棒性随传感器数量指数增长。

4. **调控必然性**：三条路径的不同时间尺度构成从"暂停→修复→强化"的渐进响应策略。单一路径无法同时满足"快速响应"（需要秒-分钟级暂停翻译防止损伤扩大）和"可持续修复"（需要小时级上调分子伴侣恢复稳态）这两个矛盾需求。PERK 先紧急制动，IRE1 再做现场修复，ATF6 最后扩容——**时间尺度的分离不是设计选择，是物理必然**。如果只有一条路径，要么响应太慢（损伤在修复到达前已不可逆），要么响应太快（每次小波动都触发完整修复 → 资源浪费）。

## 约束推导 2：为什么细胞用化学浓度场而非离散消息传递信号？

1. **多源叠加的物理成本**：一个细胞同时接收数十到数百个信号输入（激素、神经递质、细胞因子、营养物、ROS、机械力）。如果用离散消息传递——每个信号需要独立编码（信号源标识、目标地址、载荷值、优先级、TTL）。N 个信号源 → O(N) 编码成本 + O(N²) 路由成本（如果每个信号需要定向传递到特定接收方）。在连续浓度场中——所有信号源同时向胞质释放第二信使分子（cAMP、Ca²⁺、IP₃），扩散方程 ∂[S]/∂t = D∇²[S] + Σ_sources − k_deg[S] 自动完成所有信号的**线性叠加、空间分布、时间演化**。计算复杂度从 O(N²) 降到 O(1)——扩散是自然界提供的免费模拟计算机。

2. **空间编码的自然性**：同一个第二信使分子在细胞不同位置有不同含义——不是因为消息里写了目标地址，而是因为**受体分布密度在空间中不均匀**。线粒体表面 MCU 密度高 → Ca²⁺ 在那里激活 TCA 循环和 ATP 合成。质膜下 synaptotagmin 密度高 → Ca²⁺ 在那里触发分泌。核周 NF-κB 浓度决定基因转录。信号源不需要知道"线粒体、分泌泡、细胞核分别在哪"——信号源只需向胞质释放分子，接收方按自身受体分布密度选择性响应。**空间编码将路由问题从信号源转移给了接收方**——广播模型替代了寻址模型。

3. **频率编码的抗衰减性**：Ca²⁺ 和 NF-κB 用振荡频率而非振幅编码信息。Ca²⁺ 尖峰的频率（不是高度）决定了下游酶的磷酸化模式——高频触发 NFAT 核定位，低频触发 NF-κB 激活。频率信号在传播中不随距离衰减（你可以数峰值数量，不需要精确测量每个峰值的绝对高度），而振幅信号随扩散距离稀释、被缓冲蛋白捕获、被降解酶清除。在充满噪声的胞质环境中，频率调制的信噪比远高于振幅调制——这就是为什么 AM 广播在噪声中音质差而 FM 广播清晰。

4. **多路复用的物理必然性**：同一个 Ca²⁺ 离子携带多条信息——通过**频率**（快振荡 = 紧急响应，慢振荡 = 维持性信号）、**振幅**（高振幅 = 近场信号，低振幅 = 远场扩散后的残余）、**空间**（核周高浓度 vs 质膜下高浓度 vs 线粒体内高浓度）的三维编码。这是信息论上的最优压缩——用最少的分子种类传递最多的信息维度。不这样做 → 数百种不同的信号分子 → 数百种不同的受体 → 数百个不同的降解通路 → 基因组编码成本爆炸。Ca²⁺ 的"一种分子，N 种语义"不是自然界的权宜之计——是信息论上唯一可扩展的信号架构。
