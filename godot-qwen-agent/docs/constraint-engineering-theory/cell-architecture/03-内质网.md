## 核心约束问题

### 约束不变量 (Constraint Invariant)

```
[Ca²⁺]_ER ≈ 500μM (总, 游离 ~50-100μM) ∧ [Ca²⁺]_cytosol ≈ 100nM → 梯度 ≈10³-10⁴
∧ [未折叠蛋白] < UPR 激活阈值（BiP 的缓冲容量决定）
∧ SERCA 泵活性 > ER Ca²⁺ 泄漏速率（静息时净摄入为正）
∧ 氧化还原环境——氧化(利于二硫键形成), E_GSH/GSSG ≈ −210mV（高氧化）
```

### 失效模式 (Failure Mode)

```
[未折叠蛋白] > BiP 缓冲容量（分级-小时级）
  [Y → UPR 三传感器(IRE1, PERK, ATF6)激活——暂停翻译、上调伴侣、增强ERAD——买时间]
  → 适应期: 全局翻译暂停(PERK-eIF2α), 伴侣↑(XBP1s), ERAD↑
  → 如果UPR失败（应激持续）→ ATF4→CHOP 累积（小时-天级）
  → CHOP↑→BCL-2↓+BIM↑（天级）
  [Y → GADD34 去磷酸化 eIF2α 恢复翻译——但若CHOP已到阈值, 恢复翻译反而加速凋亡蛋白合成]
  → BCL-2 家族失衡→BAX/BAK 寡聚化→MOMP（不可逆）
  [N → MOMP后凋亡通路激活，不可逆]
```

## 物理结构

单层连续膜网络——占细胞总膜面积 ~50%。与核外膜连续。

- **粗面ER (rER)**：附着核糖体。蛋白质合成+共翻译转运入ER。
- **滑面ER (sER)**：无核糖体。Ca²⁺ 储存+脂质合成+解毒(CYP450)。
- **ER出口位点 (ERES)**：COPII囊泡形成处。ER-高尔基运输起点。

## 分子机制

### 蛋白质折叠QC

```
新生肽链→Sec61转位子入ER→BiP(分子伴侣)结合→防止聚集
  → 寡糖基转移酶(OST)→N-糖基化→calnexin/calreticulin循环→辅助折叠
  → PDI(二硫键异构酶)→催化二硫键形成和重排

折叠失败→ERAD(ER相关降解): 错误折叠蛋白→逆向转位到胞质→泛素化→蛋白酶体降解
  或→ER自噬(ER-phagy): 大片ER膜+错误折叠蛋白→自噬降解
```

### Ca²⁺ 稳态

```
Ca²⁺ 进入 ER: SERCA (肌质/内质网Ca²⁺-ATPase)——每泵2个Ca²⁺消耗1个ATP
  SERCA亚型: SERCA2b(广泛), SERCA1(骨骼肌——高速型)

Ca²⁺ 释放: IP3R (IP3门控——PLC→PIP2→IP3→ER释放Ca²⁺)
  RyR (Ryanodine受体——Ca²⁺诱导Ca²⁺释放 CICR, 主要在肌肉)

泄漏: 被动Ca²⁺泄漏(机制未完全阐明——可能通过Sec61或TMCO1)
```

### UPR 三传感器

| 传感器 | 静息 | 激活 | 输出 |
|--------|------|------|------|
| IRE1 | BiP 结合→单体 | 未折叠蛋白→BiP 解离→IRE1 二聚化/自磷酸化→XBP1 mRNA切割 | XBP1s→分子伴侣↑, ERAD↑ |
| PERK | BiP 结合→单体 | 同↑→PERK 二聚化/自磷酸化→eIF2α 磷酸化 | 全局翻译↓, ATF4↑→CHOP, GADD34 |
| ATF6 | BiP 结合→ER滞留 | 未折叠蛋白→BiP 解离→ATF6→COPII→高尔基→被S1P/S2P切割→释放ATF6f | ATF6f→XBP1(放大), 分子伴侣 |
