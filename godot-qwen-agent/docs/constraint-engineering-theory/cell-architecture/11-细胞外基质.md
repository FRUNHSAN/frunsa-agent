**许可**：CC BY-ND 4.0

## 核心约束问题

### 约束不变量 (Constraint Invariant)

```
ECM 刚度(E)匹配组织功能——脑 ~0.1-1 kPa, 肌肉 ~10 kPa, 骨 ~GPa
∧ 整合素介导的力传导——细胞感知 ECM 刚度 → 调节基因表达(YAP/TAZ)
∧ ECM 降解(MMP)速率 ≤ ECM 合成速率（维持结构完整性）
∧ 基底膜——上皮/内皮细胞的极性锚定面(IV型胶原+层粘连蛋白——选择性通透)
```

### 失效模式 (Failure Mode)

```
MMP 过度活跃——ECM 降解 > 合成
  → 组织强度下降→结构失效(动脉瘤破裂, 关节软骨磨损)
  → 基底膜破损——上皮细胞失去极性锚定→EMT(上皮间质转化)→侵袭/转移
  [Y → TIMP(MMP组织抑制剂)平衡——但当 MMP↑ 超过 TIMP 容量时失效]

ECM 异常硬化(纤维化)
  → 刚度↑→整合素信号持续激活→YAP/TAZ 持续核定位→成纤维细胞持续活化→更多 ECM→恶性循环
  [N → 纤维化不可逆——肝硬化, 肺纤维化]
```

## 物理结构

**纤维蛋白**——提供拉伸强度：
- 胶原——三螺旋(~1.5nm直径)→原纤维(~20-100nm)→纤维→束。I型(骨/肌腱/皮肤), II型(软骨), III型(可扩张组织), IV型(基底膜——网状而非纤维状)
- 弹性蛋白——高度交联的随机卷曲——可拉伸至休息长度的 ~1.5× 并弹性回缩。半衰期 ~70年(几乎不更新——弹性组织老化的根源)
- 纤连蛋白——二聚体, 结合整合素+胶原+肝素。细胞组装——拉伸可暴露隐匿结合位点(=力学信号)

**间隙填充**——提供压缩强度：
- 蛋白聚糖(核心蛋白+GAG链——硫酸软骨素/硫酸乙酰肝素/透明质酸)→高负电荷→吸水膨胀→组织胶状→抵抗压缩

**基底膜**——特殊 ECM：
- IV型胶原网络+层粘连蛋白(αβγ三聚体)+巢蛋白+串珠素。上皮/内皮细胞锚定面。选择性通透(肾小球过滤)。

## 分子机制

### 整合素——力传导核心

```
整合素(αβ异源二聚体——18α+8β=24种组合)
  → 胞外域结合 ECM 配体(RGD 基序→α5β1/αvβ3 识别)
  → 配体结合→整合素聚类→粘着斑(FA)组装
  → talin 被拉伸(力依赖)——暴露 vinculin 结合位点→vinculin 加固 FA
  → FAK(focal adhesion kinase)自磷酸化→Src 结合→下游: Ras-MAPK, PI3K-Akt
  → 力传导→转录因子: YAP/TAZ(机械敏感——硬基质→核定位, 软基质→胞质滞留)
```

### MMP/TIMP 平衡

```
MMP(基质金属蛋白酶)——Zn²⁺依赖内肽酶。分泌为前酶(pro-MMP)→被切割激活。
  降解胶原(MMP-1/8/13), 明胶(MMP-2/9), 弹性蛋白(MMP-12)
TIMP(MMP 组织抑制剂)——1:1 结合抑制 MMP。4种(TIMP1-4)。
  平衡破裂→ MMP↑→ ECM 过度降解(动脉瘤/关节炎)。TIMP↑→ ECM 过度沉积(纤维化)。
```
