## 核心约束问题

### 约束不变量 (Constraint Invariant)

```
中心体数量 = 1 (G1) → 2 (S→G2) → 每个子细胞各1(分裂后)（严格每次细胞分裂复制一次——不能多不能少）
∧ 中心粒结构——9×3 微管三联体排列(母中心粒有附属结构, 子中心粒无)
∧ γ-TuRC 环——作为微管(−)端成核模板。微管(−)端锚定在中心体, (+)端向外生长
```

### 失效模式 (Failure Mode)

```
中心体过度复制(>2个)
  → 多极纺锤体——染色体分配不均→非整倍体
  → 大多数非整倍体细胞凋亡——但存活者=基因组不稳定性→癌变
  [Y → 中心体聚类——多个中心体聚成两极→假双极纺锤体——部分保护]
  [N → 不可逆基因组损伤——癌变风险]
```

## 物理结构

中心粒——两根垂直排列的圆柱体(母中心粒+子中心粒)。每根中心粒 = 9×3 微管三联体(车轮状)。周围基质(PCM)含 γ-TuRC(γ-微管蛋白环复合体)。中心粒长度 ~400-500nm, 直径 ~200nm。

G1期=1个中心体(2根中心粒)。S期=子中心粒开始生长→G2期=2个中心体(4根中心粒)→有丝分裂时两个中心体移到两极→形成纺锤体。

---

## 分子机制

### 中心体复制

```
G1→S过渡: CDK2-Cyclin E 激活→中心粒复制许可
  → Plk4 招募到母中心粒→SAS-6 自组装→前中心粒(cartwheel结构)
  → 子中心粒延伸(G2期)——半保守复制(每根母中心粒产生一根子中心粒)
```

### 纺锤体组装

```
有丝分裂开始时: 两个中心体分离→移向两极(由 Eg5 驱动蛋白推离)
  → γ-TuRC 在每个极成核微管→微管(+)端向染色体延伸
  → 动粒(着丝粒蛋白复合体)捕获微管(+)端→染色体排列到赤道板
  → 微管缩短(动粒纤维)→染色单体分离到两极
```

### 细胞周期检查点

G1/S=环境条件? DNA完整? 适宜分裂? → cyclin-CDK→进入S期
G2/M=DNA完全复制? 无损伤? → CDK1-Cyclin B 激活→进入有丝分裂
纺锤体检查点=全部染色体双极附着? → CDC20 释放→APC/C 激活→securin 降解→separase 激活→cohesin 切割→染色单体分离
