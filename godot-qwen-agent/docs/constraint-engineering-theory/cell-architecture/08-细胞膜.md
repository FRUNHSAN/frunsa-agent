## 核心约束问题

### 约束不变量 (Constraint Invariant)

```
[Na⁺]_out / [Na⁺]_in ≈ 14:1 (145mM vs 10mM——静息膜电位基底)
∧ [K⁺]_in / [K⁺]_out ≈ 35:1 (140mM vs 4mM)
∧ [Ca²⁺]_out / [Ca²⁺]_in ≈ 10⁴ (2mM vs 100nM——信号隔离)
∧ V_m ≈ −70mV (静息膜电位——Na⁺/K⁺-ATPase 3Na⁺出:2K⁺入 产生 −5mV, K⁺ 泄漏通道产生其余)
∧ 脂双层对离子不通透（所有离子运输必须通过通道/泵/转运体）
∧ 内吞速率 ≈ 外排速率（膜面积稳态）
```

### 失效模式 (Failure Mode)

```
Na⁺/K⁺-ATPase 停转(ATP耗尽, [ATP]<1mM)
  → Na⁺ 内流(K⁺外流)沿浓度梯度——被动
  → V_m 去极化(>−50mV)——电压门控Na⁺/Ca²⁺通道打开
  → [Ca²⁺]_in 急剧上升——触发坏死(necrosis)通路
  [Y → 在ATP耗尽前(<3min)恢复供能——泵重启]
  [N → ATP恢复后细胞已触发不可逆坏死——膜破裂→内容物泄漏→炎症]
```

## 物理结构

脂双层(厚度 ~5nm)。主要脂质：磷脂酰胆碱(PC, ~50%), 鞘磷脂(SM), 磷脂酰乙醇胺(PE, 内层), 磷脂酰丝氨酸(PS, 内层——正常时)。胆固醇(~30mol%——调节流动性)。

**PS不对称性**是关键约束——PS 暴露到外层 = "吃我"信号(凋亡细胞标记)。

**脂筏**：鞘磷脂+胆固醇富集微域。液-液相分离(有序相 Lo 嵌入无序相 Ld)。特定蛋白(GPI锚定蛋白, Src激酶)富集于此。

## 分子机制

### Na⁺/K⁺-ATPase——膜电位基底

```
输入: 3Na⁺_in + 2K⁺_out + 1ATP
催化: ATP水解→E1→E2构象切换→3Na⁺排出+2K⁺泵入(每次循环)
输出: 3Na⁺_out + 2K⁺_in + ADP + Pi
维持: V_m ≈ −70mV(泵贡献 −5mV, K⁺泄漏通道贡献其余); [Na⁺]out/[Na⁺]in≈14; [K⁺]in/[K⁺]out≈35
泵出Na⁺ + 泵入K⁺不对称→净电荷输出(每个循环净 −1)→生电性泵
```

### 受体类型

| 受体家族 | 激活方式 | 下游信号 | 时间尺度 |
|---------|--------|---------|---------|
| GPCR | 配体结合→G蛋白激活(GDP→GTP交换)→Gα+Gβγ分离→各自激活效应器 | 第二信使(cAMP, IP3, DAG, Ca²⁺) | ms-s |
| RTK | 配体结合→二聚化→自磷酸化→招募SH2/PTB蛋白 | Ras-MAPK级联, PI3K-Akt | s-min |
| 离子通道型 | 配体/电压/机械力→通道打开 | 离子流→膜电位变化/第二信使(Ca²⁺) | <1ms |
| 整合素 | ECM配体结合→聚类→FAK/Src激活 | 细胞骨架重组, YAP/TAZ | s-min |

### 内吞/外排——膜面积稳态

```
内吞: 网格蛋白介导——>100囊泡/min(典型哺乳动物细胞)。货物: 受体+配体(GPCR, RTK), 营养物。
外排: 组成型(持续分泌——ECM蛋白, 脂质), 调节型(储存囊泡——Ca²⁺触发释放)。
膜回收: 内吞囊泡→内吞体→分选→回收内吞体→回膜(受体再循环), 或→溶酶体(降解)。
```
