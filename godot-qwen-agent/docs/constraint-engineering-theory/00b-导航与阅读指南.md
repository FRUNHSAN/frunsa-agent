## 写作风格说明

这份文档体系采用**匕首式散文（Dagger Prose）**。

不是学术论文——不需要引 50 篇参考文献。不是民科宣言——每个直觉性洞察后面紧跟着不可辩驳的数学/生物学证据。

灵感是锤子（敲碎旧认知），严谨是水泥（浇筑新认知）。在 00 号里锤子重，在 05 号里水泥重。这就是为什么不同文档的文笔配比不同。
