## 铁律在该域的映射

| 铁律 | 在该域的物理含义 |
|------|----------------|
| #1 纯函数边界 | `kernel_step()` 无副作用。LLM 不确定性隔离在 Observer 层 |
| #2 连续控制律 | `verbosity_budget`、`tone_vector`、`critic_threshold` 全部连续——无离散跳变 |
| #3 零 NL I/O | LLM 的 token 概率（量子层）不进入内核。内核只处理退相干后的 16 维经典状态 |
| #4 形式化可重放 | `DecisionTrace` 完整快照。相同 `KernelInput` → 相同 `ControlFrame` |
| #5 零动态分配 | PluginRegistry 启动后冻结。运行时无新插件注册 |
| #6 Lipschitz | trust 变化速率有界——几句话内 trust 无法从 0.9 跌到 0.1 |
| #7 信息损失可审计 | 拓扑同态 H(ε) 度量 + 量化债务表 |
