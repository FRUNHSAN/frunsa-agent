## 域特点

| 属性 | 值 |
|------|-----|
| 时间尺度 | ms 级（60-1000Hz 帧率） |
| 约束类型 | 硬约束主导（h(x) ≥ 0） |
| 几何表示 | SDF（Signed Distance Function） |
| 预测时域 | N = 20（MPC 预测窗口） |
| 死亡定义 | 穿透一帧 / 求解器发散 / 实时预算超限 |
| 竞品参照 | AVBD (SIGGRAPH 2025)、Planar-DAT (NVIDIA 2026)、MuJoCo、IPC |

## 铁律在该域的映射

| 铁律 | 在该域的物理含义 |
|------|----------------|
| #1 纯函数边界 | 模拟确定性——相同输入 → 相同帧输出。无外部 I/O 注入不确定性 |
| #2 连续控制律 | 碰撞响应连续——`‖Δx‖` 有界，无瞬间位移 |
| #3 零 NL I/O | N/A——此域无自然语言 |
| #4 形式化可重放 | 帧重放——任何帧可以从初始状态回放 |
| #5 零动态分配 | 约束数量在编译时确定。运行时无新增接触约束 |
| #6 Lipschitz | `‖Δp‖₂ ≤ ε × dt`——角色位置/速度变化速率有界。穿透预防 |
| #7 信息损失可审计 | SDF 精度量化——离散采样的几何误差可计算 |
