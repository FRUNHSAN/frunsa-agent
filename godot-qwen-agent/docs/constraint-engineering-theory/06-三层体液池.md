# 06 — 三层体液池

**Last-verified-against-code**: `7e73374` (2026-07-04)
**预计阅读时间**: 12 分钟
**文笔配比**: 灵感 30 : 严谨 70 — 系统架构设计文档

---

细胞之间怎么通信？没有中央调度器。没有地址解码器。没有"Agent A 请和 Agent B 建立 WebSocket 连接"。只有**化学梯度**。

被感染的细胞分泌细胞因子到组织液。周围的免疫细胞被激活。它们不知道病原体是什么——它们只知道"这里有危险信号"。

这不是消息路由。这是**免疫信号传导**。这就是三层体液池的数学基础。

---

## 一、架构

[脑洞.md](../_legacy/_archive/designs/脑洞.md) 2026-06-14 定义了完整的三层信号传导体系：

```
                    淋巴池（全局广播）
                    全区域可见，TTL=60s
                ┌───────────────────────┐
                │                       │
        ┌───────┴───────┐       ┌───────┴───────┐
        │ 组织液池 A     │       │ 组织液池 B     │
        │ (搬运组 5 设备) │       │ (焊接组 3 设备) │
        │ TTL=5s, <10ms  │       │ TTL=5s, <10ms  │
        └───┬───┬───┬───┘       └───┬───┬───┬───┘
            │   │   │               │   │   │
           R1  R3  R7              R3  R2  R9
                │
                └── 重叠节点 R3 = 活桥

        内部血管（单体内部多内核）
        TTL=∞, <1ms, 物理隔离
        ┌───────────────────────┐
        │ 视觉内核 │ 规划内核 │ 运动内核 │ 安全内核 │
        │ (16维)   │ (16维)   │ (32维)   │ (8维)    │
        └───────────────────────┘
```

## 二、三层物理参数

| | 内部血管 | 组织液池 | 淋巴池 |
|---|---------|---------|--------|
| **范围** | 单体内部 | 工作组（5-10 Agent） | 全区域 |
| **延迟** | <1ms | <10ms | <1s |
| **TTL** | ∞（不降解） | 5s | 60s |
| **脉冲格式** | 完整 PeerPulse | 完整 PeerPulse | 最小摘要（仅 trust + safety + available） |
| **加密** | 不需要（物理隔离） | 可选 | 可选 |
| **访问** | 仅本地 | 组成员 | 公开 |
| **生物对应** | 自分泌（细胞信号给自己） | 旁分泌（局部组织微环境） | 内分泌（血液循环全局广播） |

## 三、重叠节点 = 活桥

> **不是池和池之间有 API 网关。是共享成员自身就是信息桥。**

R3 同时属于搬运组和焊接组。R3 在搬运组的信任下降，通过 R3 自己带入焊接组。焊接组的其他成员不知道原因——只知道"R3 现在不太可靠"。

这和免疫系统完全一样——一个细胞被感染，分泌细胞因子到组织液。周围的免疫细胞被激活。它们不知道感染源是什么。它们只知道"这里有危险信号"。

这就是为什么不需要中央调度器。**信号传导 = 耦合动力系统。**

## 四、工程实现：PoolBridge 单类三实例

同一个 `PoolBridge` 类，三个不同配置实例：

```python
internal_pool = PoolBridge(
    scope="internal",
    ttl=float("inf"),
    latency_budget_ms=1.0,
    pulse_format="full",
    encryption=False
)

tissue_pool = PoolBridge(
    scope="workgroup",
    ttl=5.0,
    latency_budget_ms=10.0,
    pulse_format="full",
    encryption=False
)

lymph_pool = PoolBridge(
    scope="global",
    ttl=60.0,
    latency_budget_ms=1000.0,
    pulse_format="summary",
    encryption=False
)
```

**和人体的血管一样——主动脉和毛细血管都是血管。壁厚不同，管径不同，但结构同源。**

## 五、数学框架

**内部血管**：耦合动力系统
```
ẋᵢ = Aᵢxᵢ + Bᵢuᵢ + Σⱼ Cᵢⱼg(xⱼ)
```
参考：耦合振子理论 (Strogatz)、收缩理论 (Lohmiller & Slotine)

**组织液池**：簇耦合格子 + 多层网络扩散
```
每个池是全连图 Gᵢ
M = {G₁, G₂, ...} 是多层网络
重叠节点 = 跨层连接 → 信息通过活桥跨层扩散
```
参考：多层网络扩散 (Gómez 2013)、重叠社区随机游走 (Palla 2005)

**淋巴池**：平均场近似
```
global_trust_mean = (1/N) Σ trust_i
```
不去追踪每个 Agent（粒子），只追踪宏观可观测量。和统计力学的"粗粒化"同构。

参考：平均场博弈 (Lasry & Lions 2007)、Vicsek 模型、Kuramoto 模型
