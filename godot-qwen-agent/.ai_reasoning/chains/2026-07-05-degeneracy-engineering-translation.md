# Context

经过对"简并性是发展趋势吗"的深度辩证，发现了三个需要显式记录的约束体系修正：

1. **简并性的定位错误**：之前将简并性视为"L3 涌现产物"或"远期发展趋势"。实际它属于 L1 基础设施——多条结构不同的路径在执行同一功能，这是涌现的**前提条件**，不是涌现的**结果**。UPR 三条平行传感路径（IRE1/PERK/ATF6）是简并性在细胞中的 L1 级实现——三条路径结构不同、失效模式不同，但它们存在的理由是"设计时就植入了"，不是"从特化结构中自发长出来的"。

2. **"趋势"vs"必然"的语言精度缺失**：Edelman/Gally (2001) 对简并性的定义来自生物学归纳观察，不是数学演绎证明。当前没有从 ODE+Lipschitz 出发推导出"简并是唯一稳态解"的完整证明链。直接宣称"必然"会违反公理 3（收敛即验证）——"细胞有简并性所以框架必须有"和"细胞有嵴所以 ODE 必须有层级结构"是同一类错误。

3. **哲学命题缺少工程翻译层**：三层文档体系（宣言→论证→工程规格）之间存在断裂——宣言中的哲学命题（"约束雕刻地形"、"简并性组织可能性空间"）无法追溯到可 falsify 的工程判据。附录 A 在 V1.0 仅记录了决策/论点和对应正文——缺少"这个决策是否正确由什么测试说了算"以及"测试失败后回溯到哪条公理"。

这三个问题共享同一个根因：**约束式工程论自身的理论-实现拓扑同态度不够**（类比 V7.9 的拓扑同态审查：当前有效行为状态 vs 连续变量之比过低）。

# Decision

1. **简并性 = L1 基础设施**。在 02-细胞同构论证.md 中明确写入层级归属：L1 提供"多个不同结构可以产生相同输出"的可能性空间，L2 在这个空间内通过约束耦合选择激活哪些简并路径，L3 的涌现行为依赖 L1 简并结构的存在但不等于简并性本身。

2. **"趋势"替代"必然"**。在 00-范式宣言.md 中将声明降级为"简并性是复杂系统在约束下维持适应性的普遍趋势"。同时在 05-内核的约束拓扑.md 中新增开放问题："待证命题：在 Lipschitz 有界 + 多目标约束条件下，简并结构是否是满足所有约束的唯一稳态解？"——把"必然性"从一个断言变成一个可追踪的研究任务。

3. **附录 A 升级为 V2.0**。新增两列：
   - **工程判据**：可测量、可 falsify 的指标（例如 `h(x) ≥ 0 在所有帧上保持`）
   - **失效模式**：判据失败后回溯到哪条公理的哪个前提
   
   新增决策行覆盖本链产生的新决策，新增判决流程（判据失败 → 定位失效模式 → 检索推导链 → 三种处置路径）。

# Rationale

## 形式的推导

**简并性的层级归属**：

```
公理 2（环境先于智能）:
  框架不应包含决策逻辑 → 框架只应维持物理约束
  → 简并路径是物理约束的一种
  → "存在多条结构不同的路径"本身是物理环境的属性，不是智能的产出
  → 简并性 ∈ L1（物理/数学基础设施）

公理 1（约束先于形态）:
  定义不变量 → 推导稳态解空间 → 发现形态
  → 简并路径的不变量: ∀ 功能 f, ∃ ≥2 条结构不同的路径 p₁≠p₂, p₁和 p₂ 的失效模式不共享
  → 这个不变量在设计阶段可定义，不需要等涌现后才观察
  → 简并性属于"先于形态的约束"，不属于"从形态中涌现的属性"
```

**"必然"的不可证性**：

```
Edelman/Gally (2001): 生物学归纳——"在所有复杂生物系统中观察到简并性"
需要补的 gap: 数学演绎——"在 Lipschitz 有界 + 多目标约束下，简并是唯一稳态解"
当前状态: gap 未补 → 不能从"普遍观察"升级为"数学必然"
公理 3（收敛即验证）: 每个生物学特征必须附带一条不依赖生物学的推导链
→ 简并性的"必然性"也需要这样一条链——目前没有
→ 保持"趋势" = 诚实 = 约束式工程自身的约束合规
```

**工程翻译层的必要性**：

```
V7.9 拓扑同态度量:
  当前 16 维只有 2 条真正的连续路径
  哲学命题 → 工程判据的映射也是离散的（多数命题没有对应判据）
  
工程翻译层 = 提高 H(ε) 的手段:
  每个 L0 命题 → 对应一个工程判据
  两个相邻的哲学状态 → 工程空间中也是相邻的（判据之间的关联可见）
  
附录 A V2.0 = 工程翻译层的形式化:
  E× 行（前置验证）→ B× 行（L1 层）→ C× 行（L2 层）→ D× 行（L3 层）
  每行有判据 → 每个判据有失效模式 → 每个失效模式指向公理
```

## 参数的标定

本链不涉及数值参数。涉及结构参数：

- 简并路径的最小数量：待楼梯 demo 跑通后根据单点故障统计确定。当前约定：每个 P0 缺口至少需要 1 条简并路径（结构不同于主路径）。
- 工程判据的 falsify 阈值：使用二值判定（通过/失败），不使用连续度量。这是设计选择——降低判据的模糊度，增加触发回溯的灵敏度。

# Alternatives

| 方案 | 评估 | 拒绝理由 |
|------|------|---------|
| 保持简并性为 L3 涌现产物 | 符合"涌现"叙事的美感——一切高级属性都是涌现的 | 违反公理 2——如果简并性不是基础设施，L2 的自组织就没有物理基底。UPR 三条路径在细胞诞生时就被植入（基因编码了三个不同的传感器蛋白），不是细胞"学会"的。工程上等价于：等 demo 跑通后才发现需要补简并路径，但 demo 已经在单路径上卡死了 |
| 宣称简并性是数学必然 | 更有冲击力，对学术发表有利 | 目前推导链不完整——无法从 ODE+Lipschitz 证明简并是唯一稳态解。公理 3 要求不依赖生物学的推导链。这条 gap 需要承认，不能假装不存在 |
| 在 00-范式宣言中保留"必然"措辞，只在论证文档中降级 | 宣言保持冲击力，论证保持严谨——各司其职 | 读者的理解是连续的——宣言中的"必然"会污染论证中的"趋势"。公理 1（约束先于形态）要求一致性：宣言也是约束体系的一部分，宣言中的断言也必须可追溯到公理 |
| 不做附录 A 升级——已有的追溯链足够 | 不增加维护负担 | 现有追溯链只记录"决策→正文"，无法从判据失败回溯到公理。E1（游戏 demo）穿模后，没有机制告诉你该改哪条公理——你需要手动推导。附录 A V2.0 把这个推导**预计算**了 |

# Future Guidance

## 刻意没做的事

- **简并路径的具体实现**：本链只定义层级归属和判据框架。具体实现（Observer 的多条降级路径、门的重叠覆盖、Event Bus 的浓度场升级）需要在楼梯 demo 跑通后根据 E2（失败模式统计）来确定。不在真空中设计简并路径。
- **"必然性"的数学证明**：本链明确标记为"开放问题/待证命题"，不尝试在本链中证明。需要独立的研究工作——可能是一篇独立的数学论文。
- **浓度场基础设施**：本链不定义扩散速率、降解 TTL、阈值参数。这些是 17-细胞工程全景 P0 缺口 #3 的内容——依赖 demo 帧级性能数据。

## 参数调参须知

- 修改附录 A 的"失效模式"列 → 检查对应的"工程判据"是否仍然可测量
- 新增决策行 → 必须同时填写"工程判据"和"失效模式"——不允许空列
- 判据失败触发回溯 → 必须在本表中记录触发轮次和处置结果——这构成了 Protocol 7 约束健康度审查的输入

# Anti-Patterns

- 不能在设计文档中宣称"简并性是 L3 涌现产物"——简并性在 L1 层是可设计的不变量，不是可等待的涌现
- 不能在 00-范式宣言中使用"必然"描述简并性——生物学归纳不能替代数学演绎，公理 3 要求独立推导链
- 不能在附录 A 中新增决策行时跳过"工程判据"和"失效模式"列——无判据的决策是不可 falsify 的，违反工程翻译层的核心功能
- 不能在判据失败后绕过附录 A 的判决流程直接修 bug——每个穿模帧都是对公理的反驳，修 bug 不修约束是治标不治本
- 不能让"待补充"行积压超过 3 条而不推进——"待补充"是债务标记，不是免责声明
