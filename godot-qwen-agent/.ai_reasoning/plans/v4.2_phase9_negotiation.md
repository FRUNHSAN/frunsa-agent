## 实现 (3 处改动)

### 1. REPL — 同意检测器 + 挂起队列 (20 行)

```python
# Repl.__init__:
self.pending_consent: list[dict] = []  # 需要用户同意的提案

# 新方法:
def _detect_user_consent(self, text: str) -> str | None:
    """返回 '同意', '拒绝', 或 None"""
    t = text.strip()
    if any(w in t for w in ("可以", "好", "行", "同意", "没问题", "嗯行", "好的")):
        return "同意"
    if any(w in t for w in ("不用", "不行", "别", "不了", "不要")):
        return "拒绝"
    return None
```

### 2. REPL — 健康检查处改执行路径 (10 行)

在 `kernel_execute_repairs(actions)` 之前:

```python
# 在 execute 之前: 协商门控
consent_actions = [a for a in actions if a["action"] in ("lower_autonomy", "raise_autonomy")]
auto_actions = [a for a in actions if a not in consent_actions]

if auto_actions:
    self.c.kernel_execute_repairs(auto_actions)

if consent_actions:
    for a in consent_actions:
        self.pending_consent.append(a)
        direction = "降低" if a["action"] == "lower_autonomy" else "恢复"
        self.c.bus.emit("合同协商", f"[提议] {direction}自主权限 → {a['target']} ({a.get('reason','健康评估')})")
```

### 3. REPL — 用户输入后处理同意 (10 行)

在每轮 `input()` 之后、命令检测之前:

```python
if self.pending_consent:
    consent = self._detect_user_consent(user)
    if consent == "同意":
        for a in self.pending_consent:
            self.c.kernel_execute_repairs([a])
            self.c.bus.emit("合同协商", f"[执行] {a.get('action')} → {a.get('target')}")
        self.pending_consent.clear()
    elif consent == "拒绝":
        self.c.bus.emit("合同协商", "[取消] 用户拒绝, 保持当前权限")
        self.pending_consent.clear()
    # else: 不相关 → 保留在队列中, 继续等待
```

## 边界守卫

- 同意词汇是包容的 (很多变体), 拒绝词汇是包容的
- 短词 (<3 字符) 只在匹配同意时才处理
- 如果用户回复不相关 → 提案保留, 不丢弃, 下一轮继续等待
- 单次最多处理一条提案 (避免复杂协商状态)
