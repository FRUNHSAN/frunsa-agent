# V9.1：RealTrackC 管道 — 旧 track_c.py 执行逻辑迁移到 V9 Harness

**日期:** 2026-06-14
**状态:** 修订中 — 发现 tool_calls 缺失桥接层
**基线:** V9.0 全链路跑通 | 内核 + 4 总线冻结 | 30 测试全绿 | RealTrackC 已落地

---

## 背景

V9.0 CLI 已跑通。RealTrackC（Tool Execution + Critic）已落地。
但发现一个架构缺口：**内核决定 EXECUTE_TOOL，但 tool_calls 永远是空元组。**

```
内核: next_action = EXECUTE_TOOL  ← 正确决策
      tool_calls = ()             ← 空。内核不管"调哪个工具"
      
RealTrackC: 收到 0 个工具 → 不执行 → Critic 无结果可评审 → 空回复
```

V8.4 的 Planning LLM 负责"调哪个工具"——但 V9 把 Planning 从 Track C 移除了（正确的——避免双重决策权冲突）。但删了之后没有补上桥接层。

## 修订：新增 Harness 层 `_resolve_tools` 函数

### 职责边界

```
内核:   决定"该不该走工具路径"（SHOULD we go?）
        → 8 门路由 → EXECUTE_TOOL  ← 已做

Observer: 理解"用户说了什么"（WHAT did they say?）
        → ObservationResult  ← 已做

_real_tools (新增): 翻译"用户想做什么"→"该调哪个工具"（WHICH tools?）
        → Harness 层。LLM 轻量调用。不决策"该不该"——只翻译"意图→工具列表"

RealTrackC: 执行工具 + 评审结果（EXECUTE + REVIEW）
        → Tool → Critic  ← 已做
```

**`_resolve_tools` 不是 Planning——是路径解析。** 和 Linux 的 `path_resolution` 一样：内核决定"该读文件"，glibc 翻译"文件名→inode"。

### 数据流修订

```
Harness._execute():
  if frame.next_action == EXECUTE_TOOL:
    # 新增: 翻译用户意图 → 具体工具列表
    tool_calls = await self._resolve_tools(user_text, frame.data_policy)
    result = await self.track_c.run(user_text, policy, tool_calls, ...)
```

## 三个审查点（红队强制要求）

### A. DataPolicy 约束 Planning/Critic

调用 `llm.execute(target="llm://critic", ..., policy=policy)` 时，LLM Bridge 的 `_translate_policy()` 自动将 `verbosity_budget` → max_tokens，`tone_vector` → temperature，`forbidden_patterns` → stop 序列。RealTrackC 只需透传 `policy` — 不自己拼温度。

### B. Tool 调用异常隔离

每个 `tool.execute()` 包裹 `try/except`。异常 → 结构化错误对象 `{"tool": ..., "result": None, "error": str(e)}` 注入 Critic context — Critic 判断是否重试。

### C. 零自然语言泄漏到内核

`run()` 返回 `{"text": ..., "track": "C"}`。事件 `emit("TOOL_FAILURE", ...)` 用 `MappingProxyType({...})` — 纯结构。内核只收到 KernelEvent — 不含自然语言。

### 新文件：`harness/track_c.py`（~130 行）

```python
class RealTrackC:
    """Tool Execution → Critic — with retry loop driven by policy.safety_threshold."""

    def __init__(self, llm_bridge, tool_bridge, event_bridge, max_retries=2):
        self.llm = llm_bridge
        self.tool = tool_bridge
        self.event = event_bridge
        self.max_retries = max_retries

    async def run(self, user_text, policy, tool_calls, round_count) -> dict:
        tool_results = []
        t0 = time.perf_counter()

        for attempt in range(self.max_retries + 1):
            # Step 1: Tool Execution (fault-isolated, structured errors)
            if attempt == 0:
                for tc in tool_calls:
                    tool_name = tc.get("tool", "")
                    if not tool_name:
                        continue
                    try:
                        resp = await self.tool.execute(
                            f"tool://{tool_name}", tc.get("params", {}),
                            policy, f"tool_{round_count}_{tool_name}")
                        tool_results.append({
                            "tool": tool_name,
                            "result": resp.payload.get("result", str(resp.payload)),
                            "error": None,
                        })
                    except Exception as e:
                        tool_results.append({
                            "tool": tool_name, "result": None,
                            "error": str(e),
                        })
                        self.event.emit("TOOL_FAILURE", MappingProxyType({
                            "tool": tool_name, "error": str(e),
                        }))

            # Step 2: Critic — policy 透传
            critic = await self.llm.execute(
                "llm://critic",
                {"user_query": user_text, "tool_results": tool_results},
                policy, f"critic_{round_count}_{attempt}")

            # Step 3: Score check using kernel's dynamic threshold
            score = self._parse_score(critic)
            if score >= policy.safety_threshold:
                break

        # Emit latency telemetry
        latency_ms = (time.perf_counter() - t0) * 1000
        self.event.emit("TRACK_C_LATENCY", MappingProxyType({
            "latency_ms": latency_ms, "attempts": attempt + 1,
        }))

        return {"text": critic.payload.get("text", ""), "track": "C"}

    @staticmethod
    def _parse_score(resp) -> float:
        text = resp.payload.get("text", "")
        # Critic 输出 JSON: {"pass": true/false, "score": 0.0-1.0, "reason": "..."}
        import json, re
        try:
            m = re.search(r'\{[^}]+\}', text)
            if m:
                data = json.loads(m.group())
                return float(data.get("score", data.get("pass", 0) * 1.0))
        except (json.JSONDecodeError, ValueError):
            pass
        return 0.50  # fallback: 中性
```

## 三、ODE 积分器（冻结）

```python
# 时间常数（V9.0 默认值 — ⚠️ 全部未标定）
TAU_TRUST_DECAY = 120.0     # 信任受损恢复
TAU_TRUST_BUILD = 600.0     # 信任建立
TAU_ERROR_DECAY = 30.0      # 误差遗忘
TAU_TSR_WINDOW = 300.0      # 工具成功率窗口

# 脉冲系数（⚠️ 移植自 PLAN2 EMA α，非脉冲标定）
ETA_TRUST_FAIL = -0.30      # 失败脉冲：向 0.0 跃变，乘 trust
ETA_TRUST_ADOPT = 0.10      # 采纳脉冲：向 1.0 跃变
ETA_TSR_FAIL = -0.20
ETA_TSR_SUCCESS = 0.20

TRUST_FLOOR = 0.05          # ⚠️ 工程直觉 — 防止脑死亡

def _safe_ema(current, target, dt_sec, tau):
    """帧率无关 EMA: 1 − e^(−dt/τ)。任何 dt 不超调。"""
    if tau <= 0 or math.isinf(tau):
        return current
    lambda_factor = 1.0 - math.exp(-dt_sec / tau)
    return current + lambda_factor * (target - current)

def integrate_state(
    prev_ode_vector: tuple[float, ...],   # 4 ODE 维: [trust, e_t, tsr, sm]
    input_raw_vector: tuple[float, ...],  # 16 维当前观测
    events: tuple[KernelEvent, ...],
    dt_ms: float,
    dynamics: TrustDynamics,
) -> tuple[float, ...]:
    """
    顺序: 脉冲响应（事件驱动）→ 连续松弛（时间流逝）
    ODE 维: 从 prev_ode_vector 起步积分，不适应 input_raw_vector 的 ODE 维
    INSTANT 维: 从 input_raw_vector 直接取
    """
    dt_sec = dt_ms / 1000.0
    result = list(input_raw_vector)

    trust = prev_ode_vector[0]
    e_t   = prev_ode_vector[1]
    tsr   = prev_ode_vector[5]
    sm    = prev_ode_vector[7]

    # Phase 1: 脉冲
    for event in events:
        if event.event_type == "TOOL_EXECUTION_FAILURE":
            trust = trust + dynamics.eta_trust_fail * trust       # 向 0 跃变
            e_t = 1.0
            tsr = tsr + dynamics.eta_tsr_fail * tsr
        elif event.event_type == "TOOL_EXECUTION_SUCCESS":
            trust = trust + dynamics.eta_trust_adopt * (1.0 - trust)
            tsr = tsr + dynamics.eta_tsr_success * (1.0 - tsr)

    # Phase 2: 连续松弛
    e_t = _safe_ema(e_t, 0.0, dt_sec, dynamics.tau_error)
    tsr = _safe_ema(tsr, 1.0, dt_sec, dynamics.tau_tsr)

    # trust 三段式松弛
    if trust < 0.15:
        trust = _safe_ema(trust, 0.30, dt_sec, dynamics.tau_decay)
        trust = max(trust, dynamics.trust_floor)
    elif trust < 0.50:
        trust = _safe_ema(trust, 0.50, dt_sec, dynamics.tau_decay)
    else:
        trust = _safe_ema(trust, 1.0, dt_sec, dynamics.tau_build)

    result[0] = max(dynamics.trust_floor, min(1.0, trust))
    result[1] = max(0.0, min(1.0, e_t))
    result[5] = max(0.0, min(1.0, tsr))
    result[7] = sm  # RESERVED: 保持 1.0

    return tuple(result)
```

def _check_mode_pre_exit(sv, current_mode, signals) -> SystemMode:
    if current_mode == SystemMode.TRUST_CRISIS and sv[0] >= 0.10:
        return SystemMode.NORMAL
    if current_mode == SystemMode.VARIANCE_CRISIS and signals.trust_var <= 0.25:
        return SystemMode.NORMAL

### 4.3 8 个门（DEFAULT_GATES 优先级元组）

```
P0  社交信号          → GENERATE         is_social_signal
P1  信任危机          → WAIT             trust < 0.10 → TRUST_CRISIS
P2  MetaAdapt 升级   → WAIT             meta_escalated → ESCALATED
P3  MetaAdapt 放松   → GENERATE         meta_is_relaxed → NORMAL
P4  冷启动 (≤2轮)    → TOOL/GENERATE    context_depth > 0.40 → TOOL, else GENERATE
P5  e_t 升 + streak≥2 → TOOL            e_inc_streak≥2 ∧ e_t>0.55
P6  e_t 降 + streak≥3 → GENERATE        e_dec_streak≥3
P7  方差安全阀         → WAIT            trust_var > 0.35 → VARIANCE_CRISIS
```

### 4.4 route_controller 核心

```python
def route_controller(sv, state, signals, gates=DEFAULT_GATES):
    # 1. streak 更新（先算 — 供门使用）
    new_inc = state.e_inc_streak + 1 if sv[1] > state.prev_state_vector[1] + 1e-6 else 0
    new_dec = state.e_dec_streak + 1 if sv[1] < state.prev_state_vector[1] - 1e-6 else 0

    # 2. pre-exit（环境评估）
    pre_exit_mode = _check_mode_pre_exit(sv, state.current_mode, signals)

    # 3. 构造 eval_state（streak 已更新，mode 已 pre-exit）
    eval_state = KernelState(
        prev_state_vector=state.prev_state_vector,
        prev_raw_state_vector=state.prev_raw_state_vector,
        current_mode=pre_exit_mode,
        round_count=state.round_count,
        e_inc_streak=new_inc, e_dec_streak=new_dec,
        slot_registry=state.slot_registry,
    )

    # 4. 门仲裁（优先级链）
    triggered = None
    for gate in gates:
        result = gate(sv, eval_state, signals)
        if result is not None:
            triggered = result
            break

    # 5. 默认：无门触发 → GENERATE
    if triggered is None:
        action = NextAction.GENERATE_RESPONSE
        trace = DecisionTrace("DEFAULT_FALLTHROUGH", "No gates triggered", MappingProxyType({}))
        final_mode = pre_exit_mode
    else:
        action = triggered.action
        trace = DecisionTrace(triggered.gate_id, triggered.reason, triggered.operands)
        final_mode = triggered.next_mode if triggered.next_mode is not None else pre_exit_mode

    new_state = KernelState(
        prev_state_vector=sv, prev_raw_state_vector=state.prev_raw_state_vector,
        current_mode=final_mode, round_count=state.round_count + 1,
        e_inc_streak=new_inc, e_dec_streak=new_dec,
        slot_registry=state.slot_registry,
    )
    return action, trace, new_state
```

## 五、安全仲裁器（冻结）

```python
MAX_GRADIENT_NORM = 0.30
SPARSITY_SENSOR_FAULT = 0.80    # ⚠️ 未标定
SPARSITY_ANOMALY = 0.60         # ⚠️ 未标定

class ShieldFlag(IntFlag):
    NONE = 0
    LIPSCHITZ_CLIPPED = 1 << 0
    ACTION_DOWNGRADED = 1 << 1
    SLOT_RL_ACTIVE = 1 << 2
    NAN_DETECTED = 1 << 3
    CRITICAL_CLAMP = 1 << 4

def _hoyer_sparsity(delta_vec: tuple[float, ...]) -> float:
    """Hoyer 稀疏度 ∈ [0,1]。只在独立维 [0:8] 上计算。1=单维尖峰，0=全均匀。"""
    independent = delta_vec[:8]
    l1 = sum(abs(x) for x in independent)
    l2 = math.sqrt(sum(x*x for x in independent))
    if l2 < 1e-10:
        return 0.0
    return (math.sqrt(8) - l1/l2) / (math.sqrt(8) - 1)

def safety_arbiter(
    action, gate_id, route_trace, safe_sv, raw_delta, raw_delta_vector, slot_registry,
) -> tuple[NextAction, DecisionTrace]:
    flags = ShieldFlag.NONE
    sparsity = _hoyer_sparsity(raw_delta_vector)

    # 三级降级（大小判别 + 结构判别）
    if raw_delta > 5 * MAX_GRADIENT_NORM:
        if sparsity > SPARSITY_SENSOR_FAULT:
            flags |= ShieldFlag.LIPSCHITZ_CLIPPED          # 单维尖峰 → 传感器故障，只标记
        else:
            action = NextAction.WAIT                        # 多维协同 → 真实剧变，强制 WAIT
            flags |= ShieldFlag.CRITICAL_CLAMP | ShieldFlag.ACTION_DOWNGRADED
    elif raw_delta > 2 * MAX_GRADIENT_NORM and action == NextAction.EXECUTE_TOOL:
        if sparsity > SPARSITY_ANOMALY:
            flags |= ShieldFlag.LIPSCHITZ_CLIPPED
        else:
            action = NextAction.GENERATE_RESPONSE
            flags |= ShieldFlag.ACTION_DOWNGRADED
    elif raw_delta > MAX_GRADIENT_NORM:
        flags |= ShieldFlag.LIPSCHITZ_CLIPPED               # 1× 只标记

    # 槽位溯源
    slot_source = "default_rule"
    # ... (按 gate_id 查找 slot_registry)

    # NaN 终检
    if _has_nan_or_inf(safe_sv.data):
        action = NextAction.WAIT
        flags |= ShieldFlag.NAN_DETECTED | ShieldFlag.CRITICAL_CLAMP

    trace = DecisionTrace(
        gate_id=gate_id, reason=route_trace.reason,
        operands=MappingProxyType({**route_trace.operands,
            "raw_delta": raw_delta, "sparsity": sparsity}),
        shield_flags=flags, slot_source=slot_source,
    )
    return action, trace
```

## 六、kernel_step() 完整组装（冻结）

```python
def _emergency_wait_output(state, safe_sv):
    """内核数学崩溃时的紧急熔断。"""
    return ControlFrame(
        next_action=NextAction.WAIT,
        data_policy=DataPolicy(verbosity_budget=0.0, tone_vector=(0.5,0.5,0.5),
                               safety_threshold=0.75, forbidden_patterns=()),
        trace=DecisionTrace("NAN_STEP3_EMERGENCY", "NaN in raw_delta",
                            MappingProxyType({}), ShieldFlag.NAN_DETECTED | ShieldFlag.CRITICAL_CLAMP, "kernel_emergency"),
        metadata=MappingProxyType({"kernel_version": "V9.0.0", "round_count": state.round_count + 1}),
    ), KernelState(
        prev_state_vector=safe_sv, prev_raw_state_vector=safe_sv,
        current_mode=SystemMode.CRISIS, round_count=state.round_count + 1,
        e_inc_streak=0, e_dec_streak=0, slot_registry=state.slot_registry,
    )

def kernel_step(
    state: KernelState,
    input: KernelInput,
    signals: RouteSignals,
    gates: tuple[Gate, ...] = DEFAULT_GATES,
    dynamics: TrustDynamics = TrustDynamics(),
) -> tuple[ControlFrame, KernelState]:
    """V9 MPC 内核 — 单步决策。纯函数。零副作用。"""

    # Step 0: NaN 入口 + 事件排序（Lamport 逻辑时钟）
    sv_raw = _sanitize_nan_and_inf(input.state_vector.data)
    events = tuple(sorted(input.event_queue, key=lambda e: e.lamport_ts))
    dt_sec = input.dt_ms / 1000.0

    # Step 1: ODE 积分
    sv_integrated = integrate_state(
        state.prev_state_vector.data, sv_raw, events, input.dt_ms, dynamics)

    # Step 2: 交互基（DERIVED 维）
    sv_full = _compute_interaction_base(sv_integrated, dt_sec)

    # Step 3: Lipschitz 向量裁剪 + 数学崩溃熔断
    prev_raw = state.prev_raw_state_vector.data
    raw_delta_vector = tuple(sv_full[i] - prev_raw[i] for i in range(STATE_DIMENSION))
    raw_delta = math.sqrt(sum(x*x for x in raw_delta_vector))

    if math.isnan(raw_delta) or math.isinf(raw_delta):
        return _emergency_wait_output(state, state.prev_state_vector)

    safe_sv = StateVector(data=tuple(_clamp_state_vector(
        sv_full, state.prev_state_vector.data, raw_delta)))

    # Step 4: Streak + Pre-exit
    current_e_t = safe_sv[1]; prev_e_t = state.prev_state_vector[1]
    new_inc = state.e_inc_streak + 1 if current_e_t > prev_e_t + 1e-6 else 0
    new_dec = state.e_dec_streak + 1 if current_e_t < prev_e_t - 1e-6 else 0
    pre_exit_mode = _check_mode_pre_exit(safe_sv, state.current_mode, signals)

    eval_state = KernelState(
        prev_state_vector=state.prev_state_vector,
        prev_raw_state_vector=state.prev_raw_state_vector,
        current_mode=pre_exit_mode, round_count=state.round_count,
        e_inc_streak=new_inc, e_dec_streak=new_dec, slot_registry=state.slot_registry)

    # Step 5: 8 门路由
    action, route_trace, post_route_mode = _route_controller_core(
        safe_sv, eval_state, signals, gates)

    # Step 6: 连续控制量
    data_policy = DataPolicy(
        verbosity_budget=_compute_verbosity(safe_sv),
        tone_vector=tuple(_compute_tone_vector(safe_sv)),
        safety_threshold=_compute_critic_threshold(safe_sv),
        forbidden_patterns=tuple(_compute_forbidden_patterns(safe_sv, signals)))

    # Step 7: 安全仲裁器
    final_action, arbiter_trace = safety_arbiter(
        action, route_trace.gate_id, route_trace, safe_sv,
        raw_delta, raw_delta_vector, state.slot_registry)

    # Step 8: NaN 出口（追加标记，不替换 trace）
    if _has_nan_or_inf(safe_sv.data) or math.isnan(data_policy.verbosity_budget):
        final_action = NextAction.WAIT
        ops = dict(arbiter_trace.operands); ops["nan_exit_intercepted"] = True
        arbiter_trace = replace(arbiter_trace,
            gate_id="NAN_EXIT_GUARD", reason="NaN at exit; overriding to WAIT",
            operands=MappingProxyType(ops),
            shield_flags=arbiter_trace.shield_flags | ShieldFlag.NAN_DETECTED | ShieldFlag.CRITICAL_CLAMP)

    # 组装输出
    sanitized_input_sv = StateVector(data=sv_raw)
    new_state = KernelState(
        prev_state_vector=safe_sv, prev_raw_state_vector=sanitized_input_sv,
        current_mode=post_route_mode, round_count=state.round_count + 1,
        e_inc_streak=new_inc, e_dec_streak=new_dec, slot_registry=state.slot_registry)

    return ControlFrame(
        next_action=final_action, data_policy=data_policy, trace=arbiter_trace,
        metadata=MappingProxyType({
            "kernel_version": "V9.0.0", "round_count": new_state.round_count,
            "lipschitz_delta": raw_delta,
        }),
    ), new_state
```

### 7.2 适配层纯函数

```python
@dataclass(frozen=True)
class AdapterState:
    last_timestamp: float
    dt_window: tuple[float, ...]         # 最近 N 个 Δt
    trust_window: tuple[float, ...]      # 最近 N 个 raw trust（来自内核 raw 轨）
    last_actual_latency_ms: float        # 上轮 Harness 实际延迟

def adapter_step(
    adapter_state: AdapterState,
    confidence: float, text_tokens: tuple[str, ...],
    is_social: bool, escalated: bool, relaxed: bool,
    discrete_events: tuple[ObservedEvent, ...],
    prev_raw_trust: float,            # 仅用于 trust_window，不进入 StateVector
    prev_raw_e_t: float,              # 备用
    current_timestamp: float,
    expected_latency_ms: float,
    base_lamport: int,
) -> tuple[StateVector, RouteSignals, tuple[KernelEvent, ...], AdapterState]:

    dt_current = max(0.0, current_timestamp - adapter_state.last_timestamp)

    # [2] context_depth (PROXY: 1.0 − clarity)
    context_depth = 1.0 - confidence

    # [3] rhythm_ratio（冷启动默认 1.0）
    new_dt_window = _update_fifo(adapter_state.dt_window, dt_current, 10)
    rhythm_ratio = 1.0 if len(new_dt_window) < 2 else (
        dt_current / max(sum(new_dt_window)/len(new_dt_window), 0.1))

    # [4] cognitive_load (PROXY: Guiraud's R + 短文本保护)
    n_tokens = len(text_tokens)
    cognitive_load = 0.3 if n_tokens < 3 else min(1.0, len(set(text_tokens)) / math.sqrt(n_tokens))

    # [6] latency_ratio
    latency_ratio = adapter_state.last_actual_latency_ms / max(expected_latency_ms, 1.0)

    # trust_var（从内核 raw trust 窗口计算）
    new_trust_window = _update_fifo(adapter_state.trust_window, prev_raw_trust, 20)
    trust_var = _compute_variance(new_trust_window) if len(new_trust_window) >= 3 else 0.0

    # 组装 StateVector — ODE 维全部 0.0 占位（内核 Step 1 从 prev_state_vector 积分）
    sv = StateVector(data=(
        0.0, 0.0, context_depth, rhythm_ratio, cognitive_load,
        0.0, latency_ratio, 0.0, *[0.0] * 8))

    signals = RouteSignals(
        is_social_signal=is_social, meta_escalated=escalated,
        meta_is_relaxed=relaxed, trust_var=trust_var)

    events = tuple(
        KernelEvent(event_type=e.event_type, lamport_ts=base_lamport + i,
                    payload=e.payload)
        for i, e in enumerate(discrete_events))

    new_state = replace(adapter_state,
        last_timestamp=current_timestamp, dt_window=new_dt_window,
        trust_window=new_trust_window)

    return sv, signals, events, new_state
```

## 八、四条总线（拓扑冻结，编码冻结）

| 总线 | 何时 | 方向 | 对标 | 编码防护 |
|------|------|------|------|---------|
| LLM Bus | 执行时 | 双向 | AHB 级 | 超时降级（DEGRADED） |
| Tool Bus | 执行时 | 双向 | APB 级 | `Semaphore(max_concurrency=5)` + 跨总线事件转发 |
| Event Bus | 执行时 | 外设→内核 | NVIC 级 | 中断合并 `(type, tool_name)` 分组 |
| Telemetry Bus | 每轮后 | 单向出 | ARM CoreSight | `asyncio.Queue` + 后台 writer（非阻塞） |

### 事件总线宪法

1. **状态保全**：管道中断时，已完成的 checkpoints 打包进 BusResponse，不丢弃
2. **中断边界**：Harness 内部重试 = MAC 层，不通知内核。重试耗尽 = 稳态失败 → 事件总线
3. **合并去重**：drain() 时按 (type, tool_name) 分组，合并同源事件
