### 1. UserProfile — 协商历史存储 (10 行)

```python
# user_profile.py
def record_consent_result(self, action: str, response: str, reason: str) -> None:
    """Phase 10: record user response to a consent proposal."""
    if not hasattr(self, '_consent_history'):
        self._consent_history = []
    self._consent_history.append({
        "action": action, "response": response, "reason": reason,
        "timestamp": time.time(),
    })
    # Keep only last 10 entries
    self._consent_history = self._consent_history[-10:]
    self.save()

def should_suppress_proposal(self, action: str) -> bool:
    """Phase 10: check if this proposal type should be suppressed."""
    if not hasattr(self, '_consent_history'):
        return False
    recent = [h for h in self._consent_history[-5:]
              if h["action"] == action and h["response"] == "拒绝"]
    return len(recent) >= 2  # 2+ recent rejects → suppress
```

## 效果

```
之前: 用户连续拒绝 raise_autonomy 3 次 → 第 4 次仍然提议 (骚扰)
之后: 用户连续拒绝 2 次 → suppress → 不再提议 (尊重历史)

之前: 用户每次都接受 → 冷却期不变 (迟钝)
之后: 将来可扩展: 频繁接受 → 缩短触发间隔 (留作 Phase 11)

记录格式:
  {action: "lower_autonomy", response: "拒绝", reason: "backlash", timestamp: ...}
```
