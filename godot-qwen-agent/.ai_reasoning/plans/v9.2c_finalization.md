## 任务 2：文件系统工具沙盒防御

**修改文件:** `components/tools/filesystem_tools.py`

**不改 `execute` 签名** — 工具返回 `ToolResult`，适配器序列化。只加路径校验。

```python
# 新增模块级常量
import os
from pathlib import Path

SAFE_SANDBOX = Path(os.getenv("AGENT_SANDBOX", "./workspace")).resolve()

def _validate_sandbox_path(requested_path: str) -> Path:
    """防目录穿越：解析后必须落在 SAFE_SANDBOX 内。"""
    SAFE_SANDBOX.mkdir(parents=True, exist_ok=True)
    target = Path(requested_path).resolve()
    if not str(target).startswith(str(SAFE_SANDBOX)):
        # 相对路径或无路径 → 收拢到沙盒（取文件名部分）
        target = SAFE_SANDBOX / target.name
    return target
```

**WriteFile.execute** — `full_path = _validate_sandbox_path(path)` 替代 `os.path.join`
**ReadFile.execute** — 同上
