## 背景

Track B 能跑，但是**静态的**——Planning 返回写死的 3 步模板，Critic 用字符数判断，
执行是 for 循环。三个真正的引擎（PlanningEngine / OrchestrationEngine / CriticEngine）
在 `engines/` 下已经完整实现——15 个文件，有 async 流式 Protocol、LLM 实现、prompt 模板、
JSON 解析器、stub 和 conformance 测试——但它们**一个都没接入** REPL 主循环。

Track C 把它们接进去，加 Scratchpad 上下文窗口，升级路由。

## 三轨分层

```
用户输入 → _route_task() embedding 分类器
│
├─ Tier 0 (Track A)        ├─ Tier 1 (Track B)       ├─ Tier 2 (Track C)
│  直连 LLM                │  静态 3 步管道           │  引擎全开
│  无规划 无工具            │  关键词路由              │  动态规划+编排+评分重试
│  ~1s 响应                │  ~8s 响应               │  ~20s+ 响应
│  "你好""拜拜"            │  "分析优缺点"            │  "帮我准备面试/写方案"
│                          │  "做个对比"              │  "深度调研XX"
│                          │                         │
│  引擎: 0/3               │  引擎: 0/3 (mock 管道)  │  引擎: 3/3 (真实引擎)
│  LLM 调用: 1 次          │  LLM 调用: ~4 次         │  LLM 调用: ~6-9 次
│  契约门控: 输出管道       │  契约门控: knowledge_    │  契约门控: 全 ActionPipeline
│                          │            search        │
```

**关键设计**：三轨共享同一套基础设施（XRayBus、Container、Blueprint），但引擎参与度不同。
Track C 是"完整版"——三个真实引擎全开。Track B 是"轻量版"——用静态计划替代 LLM 规划，
节省 3-4 次 LLM 调用。Track A 是"极简版"——零引擎，直连。

| 维度 | Track A | Track B | **Track C** |
|------|---------|---------|-------------|
| 路由 | 无 | 关键词 | **Embedding 语义** |
| 规划 | 无 | 写死 3 步 | **LLMPlanningEngine** |
| 执行 | 直调 LLM | for 循环 | **LLMOrchestrationEngine** |
| 评估 | 无 | 字符数 | **LLMCriticEngine + 重试** |
| 上下文 | prompt | 结果拼接 | **Scratchpad** |
| 降级 | 无 | Track A | **Track B → Track A** |

## 三个暗礁（Tech Lead 已标记）

### 暗礁 1：事件循环炸弹
**不用裸 `asyncio.run()`**。用 `safe_async_run()` 桥接函数——先检测当前是否有
正在运行的 loop，没有才 `asyncio.run()`，有则走线程池。防止 httpx 等异步客户端
因"绑定在旧循环上"抛 `RuntimeError`。

### 暗礁 2：Scratchpad Token 爆炸
重试时 `step_results` 堆积旧数据会撑爆上下文窗口。**喂给 Critic 前必须截断**：
只保留最后一次结果，限制 1000 字符。Scratchpad 是给 LLM 看的，不是给人类看的。

### 暗礁 3：Embedding 冷启动
路由分类器的 Embedding 模型必须在 `Repl.__init__` 预加载。常用意图向量
（"面试准备""深度分析"等）缓存起来，避免每次输入都现场算 Embedding。

---

## 风险：Async 在同步主循环里

`safe_async_run()` 每次调用 ~100ms 开销 × 3 次 = ~300ms。Phase 3 可接受。
