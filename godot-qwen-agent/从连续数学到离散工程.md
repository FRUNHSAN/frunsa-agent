# 从连续数学到离散工程

**V7.8 自检报告** | 2026-06-11

---

## 审计结论

V7.2→V7.7 构建了层论、纤维丛、梯度流、路径积分等数学模型。
代码审计发现三个系统性裂缝：

### 陷阱 1：伪连续

**数学**: `c' = c - η∇V` 连续梯度。**代码**: `_build_contract_directive()` 是 4 段 if/else 中文模板。Planning LLM 完全不收契约指令——`_do_plan()` 接收 `system` 参数但函数体内零引用。

→ **修补**: `VERBOSE_CONTINUUM` + `TONE_CONTINUUM` 替代硬编码 `v_map`/`tone_map`。过渡期用中点词数平滑切换，契约微小变化真正影响生成指令措辞。

### 陷阱 2：伪梯度

**数学**: `∇V` 势能场梯度下降。**代码**: `_contract_adapt()` 是 `if clarity_count > 3: proposal = "THEORETICAL"`。`V` 函数不存在。`CROSS_COEFFICIENTS` 是手写的 7 个猜测值。`MAX_GRADIENT_NORM = 0.3` 定义了但从未校验。

→ **修补**: `_check_lipschitz()` 在每次 sensor-driven proposal 前校验 `|new_ordinal - current_ordinal| / max_ordinal ≤ 0.3`。超限拒绝。

### 陷阱 3：单向膜

**数学**: `⊥` 开集——截面未定义，层论上同调非平凡区域。**代码**: `_classify_null_region()` 的 50 行输出最终只流入 `return None`。Agent 感知到语义真空后……什么都没做。

→ **修补**: `_clarification_needed` flag。null_region 或 gap_region 触发时，注入 `[语义状态] 上一轮输入处于语义模糊区域。请礼貌澄清，不要猜测。` 到 system prompt。仪表盘→执行器。

## 明确承认的工程妥协

以下不做——是诚实的 MVP 边界，不是 bug：

| 妥协 | 原因 | 未来 |
|------|------|------|
| ∇V 从数据学习 | 需要用户隐式反馈的奖励模型。手写 streak 是合理的 MVP | V9.x |
| 连续向量→LoRA 权重 | 需要微调基础设施 | V10+ |
| CROSS_COEFFICIENTS 从数据学 | 需要联合分布标注。7 个手写系数在 6 类命令上够用 | V7.9 |

数学是设计图纸，代码是施工脚手架。剩下的 38% 差距不是偷懒——是承认有些桥需要更大的船才能过。

## V7.8 最终方案：三次微创手术（已交付）

采纳了架构讨论后的最终设计。核心原则：
- **不消灭 if**，而是在 if 内部的文本中嵌入连续变量
- **不建 few-shot pool**，用自然语言描述过渡，让 LLM 自己插值
- **不动 Planning 逻辑**，只埋遥测为 V8.0 积累数据

### 手术 1：`_lambda_hint` 连续谱化（~20 行）

废弃 trust 的三段硬文本。`{trust:.0%}` 和 `{e_t:.0%}` 直接把连续值打入 prompt。

```
T=0.31 → "对关键决策点给出简要理由（当前信任度 31%）"
T=0.54 → "对关键决策点给出简要理由（当前信任度 54%）"
```

同一个 bin 内，prompt 文本不同——实现了真正的连续同态。

### 手术 2：TONE_CONTINUUM 过渡描述（~10 行）

WARM→PRAGMATIC 过渡时，不切 few-shot 比例，用自然语言描述：

```
"语气: 当前正在从「温和共情，语气友善自然」向「务实直白，不加修饰语」过渡。
请采用两者之间的中间风格。"
```

LLM 天然理解"中间风格"——这是它的母语。

### 手术 3：Planning 遥测埋点（~8 行）

`_do_plan()` 加一行遥测，记录被真空执行的契约状态。不改行为，只为 V8.0 积累弹药。

## V7.9 拓扑同态审计

**问题**: 连续数学空间里相邻的两个状态，在离散执行时是否表现出相似的行为倾向？
连续空间里的梯度方向，是否对应离散行为空间的合理演变？

### 审计范围

追踪 5 个连续变量在整个代码库中的每一次量化：

| 变量 | 连续范围 | 离散行为状态数 | 真连续路径 |
|------|---------|-------------|----------|
| `trust` | [0, 1] | **6** | 无 |
| `e(t)` | [0, 1] | **4** | 1 条 (→ critic θ) |
| `clarity` | [0, 1] | **5** | 1 条 (→ f_fused → branch_count → 3 bin 截断) |
| `drift` | [0, 2] | **4** | 1 条 (→ critic θ) |
| Blueprint fields | 7 个 enum | **~1152 种 prompt 组合** | 0，全部是类别 |

### trust 的 14 个量化点

T ∈ [0,1] 在 9 个文件中被 14 个阈值切割成 6 个行为区：

| 区间 | 行为 |
|------|------|
| [0.00, 0.10) | 路由=A，契约冻结，提案拒，lambda="极度保守" |
| [0.10, 0.15) | η=0.5，路由正常，lambda="极度保守" |
| [0.15, 0.30) | η=0.5，lambda="偏保守" |
| [0.30, 0.55) | η=1.0，无 lambda 提示 |
| [0.55, 0.70) | 重协商阈值以上，无 lambda |
| [0.70, 1.00] | lambda="完全自主，鼓励 DIRECT" |

**同态破裂**: T=0.31 和 T=0.54 在 0.24 的连续跨度内，行为完全不可区分。连续空间里它们是"中等偏下"和"中等偏上"——离散空间里它们是一个东西。

### 唯一的真连续路径

整个系统只有 **两条路径** 能让连续变量的微小变化产生不同的数值输出：

1. **e(t) → g(e_t) → θ**: e(t) ∈ (0.55, 0.70] 时，每 0.01 变化使 critic 阈值变化 ~0.0017。但这只在 plan 输出分数恰好落在两个 θ 值之间时才产生可观测的行为差异。

2. **drift → f_drift → θ**: drift ∈ (0.20, 0.60) 时，每 0.01 变化使 θ 变化 ~0.006。同上——需要输出分数恰好跨越阈值。

**结论: 拓扑同态质量 ≈ 35%。** 系统在大多数连续区间上是分段常数控制器——连续数学在离散边界处被截断为阶梯函数。两个状态在连续空间相邻，但在离散行为空间完全不可区分，除非它们恰好跨越一个硬阈值。

### 最大的量化鸿沟

| 鸿沟 | 连续空间 | 离散空间 | 丢失的分辨率 |
|------|---------|---------|------------|
| Blueprint → Prompt | 7 维连续梯度流 | 4×4×3×2 = 96 种 prompt 模板 | 无限 → 96 |
| trust → 行为 | [0,1] 路径积分 | 6 个区 | 连续 → 6 |
| e(t) → 路由 | [0,1] 连续误差 | A 或 C | 连续 → 2 |
| clarity → 探索 | [0,1] 连续清晰度 | 3 个 branch count bin | 连续 → 3 |
| 情绪 → 契约 | 乘积纤维联合分布 | 7 个手写交叉系数 | 连续 → 7 |

### 这意味着什么

当 trust=0.29→0.31 跨越 0.30 时，系统从 η=0.5 跳到 η=1.0——契约演化速率瞬间翻倍。在连续数学中这应该是光滑的 sigmoid 过渡，在离散工程中是硬开关。这就是为什么 V7.6 的迟滞比较器如此重要——如果没有它，trust 在 0.30 附近抖动会导致契约在两种速率之间高频振荡。

**拓扑同态不是要消除量化——是要让量化后的行为保持连续空间的邻接关系。** 当前系统在 trust 维度基本做到了（6 个区按序排列，相邻区的行为渐变），在 e(t) 维度部分做到了（4 个区有序），在 blueprint→prompt 维度基本没做到（过渡期标注是 V7.8 的第一步）。
